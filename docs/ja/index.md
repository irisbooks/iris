# IrisBooks ドキュメント

IrisBooks は、自分の AI アシスタントと使う記帳ツールです。

- **`iris` コマンドラインツール**で、AI と仕訳を作成・検証します。
- **Web アプリ**で、同期した帳簿・仕訳・レポートを確認します。

帳簿は Markdown と YAML のファイルをまとめたフォルダです。CLI はアカウントなしで
使えます。クラウド同期を追加すると、Web からのアクセスや共同作業もできます。

> **はじめての方へ**　まず [はじめに](getting-started.md) を読み、続いて
> [基本コンセプト](concepts.md) へ。それ以外は必要なときに戻れるリファレンス
> です。

## 対象読者

- **家計を把握したい方** — 領収書をすべて残さなくても、支出や残高を把握できます。
  現金残高や明細から始め、無理なく続けられる詳しさで AI と整理します。
- **事業主の方** — 自分で記帳するフリーランス、
  個人事業主、中小企業。まずは CLI と自分の AI から
  （[CLI と自分の LLM で記帳する](cli-and-llm.md)）。クラウドを使うなら Web
  アプリも追加で使えます。
- **税理士・会計事務所の方** — 多数のクライアント帳簿を扱う方。
  [自分の AI とファイルで作業する方法](cli-and-llm.md)を勧めます。顧客ごとに
  AI の作業フォルダとセッションを分け、[Web アプリ](web-app.md)は閲覧とレビューに使います。

## 60秒でわかる全体像

```text
your-book/
├── config/        # 帳簿設定 + 勘定科目表
├── raw/           # 元資料。自分でも AI でも保存できる
├── journals/      # 複式仕訳。1件1 Markdown ファイル
├── notes/         # AI や税理士と共有する作業ノート
└── compiled/      # AI 生成レポート（再生成可能）
```

明細を渡すか、起きたことを AI に伝えます。AI は元資料を `raw/` に保存し、
仕訳を考えて説明します。`iris validate` で検証し、選んだ方針に従って記帳すると、
`iris balance` で結果を確認できます。判断や質問をノートに残せば、次の会話や
別の AI に引き継げます。必要に応じて `iris sync` で記録をクラウドに同期すると、
Web アプリ・共同作業・サーバー側の変更履歴も使えます。

# Web アプリを使う

Web アプリは、事業主と税理士がレポートの閲覧、仕訳のレビュー、権限に応じた承認、
履歴の確認、クラウドのアクセス管理に使う画面です。税理士の記帳作業にも、
顧客ごとに作業環境を分けて[自分の AI と帳簿ファイルで作業する方法](cli-and-llm.md)を
勧めます。Web アプリはクラウド上の帳簿コピーを使うため、サインインと
オンライン接続が必要です。

## サインイン

アカウントはメールアドレス + パスワードで作成します。サインイン画面では次ができます。

- **ログイン** — メールアドレスを入力し、「次へ」を選びます。
  登録済みのパスキーが使える場合は、自動でパスキー認証が始まります。
  パスキーが使えない場合はパスワード入力に進みます。パスキー認証をキャンセルした場合や失敗した場合は、
  再試行するか「パスワードでログイン」を選べます。
  失敗が続く場合は、画面に表示された参照番号をサポートにお知らせください。
  認証アプリを設定すると、パスワードでのログインには 6 桁のコードも必要です。
- （受付中なら）**新規登録** — メールとパスワードを送信し、届いた確認コードで
  認証。
- 「パスワードをお忘れですか」から**パスワード再設定** — コードを受け取り、新しい
  パスワードを設定。

これらの画面の右上には言語切替（「日本語」/「English」表記）があり、
ブラウザの言語判定が違っていた場合に切り替えられます。確認コードと再設定コードの
メールは、操作していた画面の言語で届きます。招待メールは、招待した人の言語で届きます。

税理士に帳簿へ招待された場合は、招待された正確なメールアドレスで登録（または
ログイン）してください。招待は、まだ帳簿がなければ最初に開く画面に、帳簿があれば
**ダッシュボード**（と**帳簿一覧**）に表示されます。
**承認する**を選ぶと帳簿を開けます。不要なら**辞退する**を選びます。承認するまで、
その帳簿は帳簿一覧にもレポートにも AI アシスタントのツールにも現れません。

**CLI 認可**のページもあります。`iris api login` を実行するとブラウザでこのページが開き、
コマンドラインツールからのアクセスを許可するかどうかを尋ねます。自分のメールと想定どおりのツールであることを
確認して承認してください。

`iris api login --device` の場合は、表示された IrisBooks の URL を自分の
スマートフォンで開きます。サインインしてリクエスト番号を入力し、アカウント・権限・
注意書きを確認してから承認してください。自分で開始したリクエストだけを承認し、
表示されるデバイス名は未確認の情報として扱ってください。パスワード・認証コード・
パスキーを VM に渡す必要はありません。承認後、VM 専用の CLI セッションが発行されます。

### パスキーと認証アプリのバックアップ

アバターメニュー → 設定 → アカウントのセキュリティで、まず認証アプリを設定します。
QR を読み取るか設定キーをコピーし、コードを入力して確認してください。
認証アプリのデータは、機種変更や紛失に備えてバックアップしておいてください。
そのうえで、自分のデバイスにパスキーを追加できます。
予備のパスキーをもう一つ登録することもできます。パスキーでのログインには
デバイスの生体認証や PIN を使い、認証アプリのコードを追加で入力する必要はありません。
同じ画面で認証アプリの入れ替えやパスキーの削除ができます。

これらの設定を変える前に、もう一度サインインを求められることがあります。その場合は
サインインし直してください。設定を変更すると、それまでのブラウザ・CLI・API トークン・
コネクターのアクセスはすべて取り消されます。必要な場所で、ログインや接続を
やり直してください。変更の最後の処理に失敗した場合は、完了を再試行するボタンを
押します。すでに利用中の方は、好きなタイミングで設定できます。パスワードを再設定しても
認証アプリの保護は解除されません。すべての認証手段を失った場合のセルフサービス復旧は
未対応です。パスキーを使い始める前に、使えるバックアップを確保してください。

## 帳簿が表示されないとき

帳簿がまだない場合は、AI アシスタントと `iris` CLI でパソコンに帳簿を作り、
このアカウントと同期する方法が表示されます。「AI に渡すメッセージをコピー」には、
このサービスのセットアップガイドの URL と、サインイン中のメールアドレスが
含まれます。パソコンで使っている AI アシスタントに貼り付けてください。
自分で手順を進める場合は、「セットアップガイドを読む」からマニュアルを開けます。

パソコンに帳簿がある場合は、そのフォルダを AI アシスタントで開き、
同じ帳簿を接続して同期するよう頼んでください。同期後に「帳簿一覧を更新」を
選ぶと、見つかった帳簿の概要が開きます。共有された帳簿をお探しの場合は、
この画面の上に招待が表示されます。表示されないときは、招待を受けたメールアドレスで
サインインしているか確認してください。
上のアカウントメニューから、言語切替、ログアウトを利用できます。
その隣の歯車アイコン（設定）と言語アイコンは、スマートフォンでも上部バーに表示されます。
帳簿を同期する前でも、設定からパスキーや認証アプリを登録できます。

帳簿の作成には、AI とパソコン上のファイルで作業する方法を勧めます。
クラウドに直接作成したい場合は、「新しい帳簿を追加」も引き続き使えます。

## レイアウト

サイドバーは、帳簿を横断する画面でも個別の帳簿でも使えます。

- **帳簿を横断**には、集計を見るための**ダッシュボード**と**純資産**があります。
- **帳簿一覧**には、各帳簿の名前と会計年度が並びます。横断画面から帳簿を開くと
  その帳簿の概要に移動します。ある帳簿を見ている途中で別の帳簿に切り替えると、
  切り替え先でも同じ種類の画面（仕訳帳、レポートなど）が開きます。元の帳簿で
  指定していたフィルターやファイルの選択は引き継がれません。帳簿名の横の矢印を
  押すと、画面を切り替えずに、その帳簿のメニューだけを開けます。一度に展開する帳簿は一つで、
  概要・仕訳帳・アクティビティ、各レポート、ファイル・勘定科目・ノート・
  年度の締め・帳簿の設定を選べます。
- **締め済みの帳簿**には、締め済みとアーカイブ済みの帳簿をまとめています。
  その帳簿の URL を直接開くと、グループとメニューが自動で展開されます。
- **帳簿の管理**から一覧ページ、**新しい帳簿を追加**から作成画面を開けます。
  帳簿が1冊の場合も利用できます。

上部バーには「ダッシュボード」「純資産」「帳簿の管理」「設定」「新しい帳簿を追加」
など、現在の画面名が表示されます。帳簿の中では帳簿名と会計年度が表示され、
年度は**年度の締め**へのリンクです。スクロールしても上部バーは表示され続け、
サイドバーやスマートフォンのメニューはその直下に表示されます。スマートフォンでは、
左上のメニューボタンから同じ操作を行えます。

右上の**歯車アイコン**から設定を開き、**言語アイコン**から日本語と英語を切り替えられます。
言語アイコンにカーソルを合わせると、切替先の言語名（「日本語」/「English」）が表示されます。
隣の**ヘルプアイコン**を選ぶと、このマニュアルが新しいタブで開きます。
これらのアイコンは、帳簿を横断する画面、個別の帳簿、初回のセットアップ画面で使えます。

右上の**アバター**からは、どこにいてもアカウントメニューが開けます。
**設定**（後述）、言語切替、ログアウトです。言語の項目は、常に切り替え先の
言語名（「日本語」/「English」）で表示されます。画面が読めない言語になっても、
この項目だけは読めるので、元に戻せます。配色テーマを含め、それ以外は
すべて設定ページにあります。

画面ごとに URL があり、ダッシュボードは `/app/`、純資産は `/app/networth`、
帳簿の一覧は `/app/books`、個別の帳簿は `/app/b/<book-id>/...` です。
ブックマークしたり、別々のブラウザタブで開いたりできます。表示する帳簿は
URL で決まり、前に開いた帳簿には左右されません。既存のレポートのフィルターや
ファイル選択も URL に保持されます。

## ダッシュボード

帳簿を横断して、純資産・合算損益・上位変動要因・未記帳の件数を確認するホーム
画面です。帳簿が1冊でも表示します。個別の帳簿の損益フロー図と貸借対照表の
構成は、その帳簿の**概要**で確認できます。サイドバーで帳簿を開いても集計への
算入設定は変わりません。集計する帳簿は各レポートの設定で選びます。

帳簿横断のレポート（ダッシュボードと純資産）は、1日1回まとめて集計したデータを
表示します。画面には集計した時刻が出ます。仕訳を同期した後や価格を記録した後は、
見ている画面で「**集計を実行**」を選ぶと、その画面のデータを集計し直します。
ダッシュボードで実行すると、損益のデータと純資産のデータの両方を更新します。
純資産の画面で実行すると、純資産のデータだけを更新します。リモートコネクタの
純資産も、同じ集計結果を読みます。

集計の対象は、クラウドに同期したデータだけです。日付の変更と現預金の切り替えは、
集計し直さずに、取得済みのデータからその場で計算します。帳簿の選択や表示通貨を
変えた場合は、その条件で別に集計します。

純資産の画面は、次の集計が待機中・実行中・自動再試行の待機中のあいだも、前回成功した
レポートを表示し続けます。その間に「集計を実行」を繰り返し選んでも、動く処理は
1つだけです。集計が成功または失敗したあと、次に実行できるのは60秒後で、残り時間は
画面に表示されます。更新に失敗した場合は、前回の結果に警告を添えて表示します。
日次の集計は、UTC の午前0時を過ぎ、進行中の処理と待ち時間が終わったあとに
実行できるようになります。

帳簿の通貨が揃っていない場合は、集計通貨を設定してください
（`iris api config set --base-currency JPY`）。合算損益に**換算レート**が表示され、
他の通貨ごとに、使用したレートとその記録日が並びます。各レートは編集でき、
別の値を入力すると合計がその場で再計算されます。この編集は表示にのみ反映され、
保存されません。レートを残すには `iris price add --unit USD --price 155` で
記録してください（純資産で保有を評価するのと同じ価格ストアです）。

レートが未記録の通貨は入力欄が空になり、その通貨の帳簿は合計に含めず個別に
表示します。レートを記録し忘れても、合計が気づかないうちに変わることがないよう、
記録がないことを画面で分かるようにしています。

## 純資産

**純資産**は、対象帳簿の資産から負債を差し引いた額です。グラフには2つの値を
表示します。**資産評価額**は折れ線で、**残存保有分の取得額**は青緑色の塗りつぶしで
示し、両者の差額も表示します。

現預金を含めるチェックボックスをオンにすると、現預金と簿価で評価する資産を、
取得額の上に黄土色で積み上げます。このときの合計は**取得額 ＋ 現預金・簿価評価の資産**と
表示されます。内訳は、凡例・ツールチップ・日付別の表で確認できます。現預金で資産を
購入した場合、内訳は変わりますが、合計額は変わりません。取得額は、累計の入金額でも
実現損益でもありません。チェックボックスの状態は、グラフと合計の両方に同じように
反映されます。

負債は純資産の額には反映されますが、取得額には含めません。`owner: true` を付けた
科目とその配下の科目は、対象から除きます。

**設定**タブで対象帳簿を選びます。各年度の帳簿は、その会計年度の期間だけ集計に
含まれます。`iris yearend` は完全な期首ロットと取得原価を翌年度へ引き継ぐため、
翌年度の帳簿は単独で使えます。過去の期間を見る場合は過年度の帳簿も選びます。
帳簿のない年度は空白です。年度が変わっただけでは購入や入金を加算しません。

クラウドの集計は、開始した時点の同期済みデータをひとまとまりで読み取り、再試行の
ときも同じデータを使います。そのため、読み取りの最中に仕訳が更新されても、古い内容と
新しい内容が混ざることはありません。集計の開始後に行った変更を含めるには、同期して
からもう一度集計を実行します。

評価には、その日までに記録された価格を使います。価格がない保有資産は簿価で評価し、
価格が不足していることを画面に示します。期首の取得原価が分からない場合や、売却時の
原価の計算方法が決まっていない場合は、取得額を空白にします。簿価を評価替えしても、
その額は取得額に加えません。グラフに表示するのは、週ごとの値と、選択した期間の末日の
値です。正確な金額は日付別の表で確認できます。DuckDB ファイルをダウンロードすれば、
SQL やピボットで自分で分析することもできます。

集計の対象は、通常の帳簿では記帳済の仕訳、会計ビューのある帳簿では承認済みの既定
ビューです。ビューの識別子は「追加フィールド → 承認済み会計ビュー」で確認できます。
入力が変わったあとは、再承認するまで集計できません。

**追加フィールド**を開くと、仕訳明細・固定資産・帳簿設定に保存された値を確認できます。
記録の種類を選び、**フィールドを探す**で保存されたパスと記録数を100件ずつ確認します。
パスの検索は、大文字・小文字を区別する文字列の部分一致です。
`/tax/category` のようなパスを選択すると、その値を調べられます。
**記録ごと**では、元の記録と値・型を100件ずつ表示します。
JSON の値による完全一致の絞り込みもでき、`100` と `"100"` を区別します。
長い値は先頭の4,096文字を表示します。全体はレポートをダウンロードして確認できます。

**値ごとに集計**では、型を区別したグループごとに件数と合計を表示します。
整数は正確に合計し、小数の合計には近似値を示す `≈` を付けます。値や合計が範囲を
外れた場合は、元の値を残して「計算できる範囲外」と表示します。
文字列・配列・未記入の値は合計に含めず、表示は先頭の100グループまでです。
大きな整数も全桁を保持し、未記入と明示的な `null` を区別します。
対象の帳簿と集計時点は、表示中のレポートと同じです。その後の変更を含めるには、
同期して集計を更新してください。古い形式のレポートも再集計が必要な場合があります。

**項目の参照情報を読む**では、現在の同期済み帳簿から定義やガイドを開きます。
集計結果から参照する場合は、対象の帳簿を選択してください。
参照情報は、表示中のレポートの集計時点より新しい場合があります。帳簿設定からも、
保存されたパッケージの選択・設定、項目・タスクの定義、ガイドの指定節やタスクの例を
読めます。帳簿のリビジョンと読み込み日時も表示します。取得できない情報はその旨を示します。
クラウドは、パッケージに互換性があるか、適用できるか、項目が必須かを判定しません。
検証や計算も行いません。これらを確認したいときや、未同期の変更を含めて見たいときは、
ローカルで AI か CLI を使ってください。

市場価格や為替は自動取得しません。`iris price add` で記録し、同期後に集計を更新して
ください。取得時の為替がある場合は取得原価に使います。数値は資産状況をつかむための目安です。

## 仕訳帳

**仕訳帳**は取引の一覧です。各行に日付、**摘要**（仕訳の説明本文の1行目）、取引先、
金額、ステータスが並びます。スマートフォンでは仕訳ごとのカードで表示され、
絞り込みの項目は**絞り込み**ボタンの中にまとまります。ここから次ができます。

- **絞り込み・検索** — 日付範囲、取引先、フリーテキスト、ステータス（記帳済 /
  下書き / 締め済み …）、金額（等しい / 超 / 未満）。
- 絞り込んだ一覧を CSV に**エクスポート**。
- **仕訳帳**表示に切り替えると、紙の仕訳帳と同じ形で読めます。表示するのは記帳済の
  仕訳だけで、古い順に並びます（下書きはまだ帳簿に入っていないため表示しません）。
  各仕訳の明細行は、借方の科目・金額と貸方の科目・金額を横に並べて表示します。
  摘要には明細行のメモを、メモがなければ仕訳の説明を表示し、取引先も添えます。
  期間内の仕訳をすべて読み込むと、最後に合計を表示します。この表は印刷でき、
  CSV にも同じ行が出力されます。
- 仕訳を**開いて**詳細を見る — 日付、取引先、ステータス、タグ、添付された元資料
  （クリックで資料へ）、借方/貸方と合計を持つ明細表、説明本文。
- **下書きを承認** — 詳細ページで**仕訳のテキスト**を確認し、**記帳**を選びます。
  一括承認では、選択した各仕訳のテキストを先に表示してから**確認した仕訳を記帳**を
  選びます。確認した版だけが承認対象です。仕訳が変わった場合は、改めて確認してください。

作成・編集・削除・復元は、ローカルのファイルと、権限のある CLI/API 操作で
行います。Web の記録は、確認済みの `draft → posted` の承認を除いて読み取り専用です。
承認時も、未知のフィールド、数量、ロット、コメント、本文を保持します。
下書きや記帳済の仕訳を画面で編集するには、ローカルのフォルダを
[`iris view`](iris-view.md) で開きます。編集内容は次の同期でこのアプリに反映されます。

帳簿に名前付きの会計ビューを定義している場合、仕訳の金額には**ビューの参考値**と
表示されます。すべてのビューに共通する部分だけの仕訳も同じです。詳細ページには
既定のビューの名前が表示され、CSV にも、計算結果が未承認であることが記録されます。
会計ビューを使っていない帳簿では、この説明は読み飛ばしてかまいません。

仕訳の承認で記帳済になるのは、ビューが共有する元の記録です。ビューごとの計算結果は、
これでは承認されません。計算結果は、ローカルで作成して同期したうえで、
**帳簿設定 → 会計ビューの承認**で入力と計算後の仕訳を確認して承認します。承認済みの
ビューは、レポートで選択できます。CSV と元帳への移動にも、そのビューの識別子が
残ります。未承認の計算結果と、入力が変わったあと再承認していない計算結果は、
レポートに使えません。

### 履歴と「締め後」の警告

仕訳詳細ページの**履歴**パネルには、そのファイルの訂正・削除の履歴がすべて残ります。
書き込み・削除・移動の各操作と、実行者・日時・出所・理由です。年度を締めたあとに再オープンし、
その間に変更した仕訳には、**「締め後」**バッジが付きます。
訂正・削除の履歴を、仕訳1件ごとに見る画面です。

日付が**締めた会計年度**に入っている仕訳は「締め済み」と表示され（一覧・
締め済みフィルタ・詳細ページ）、編集・削除・記帳はできません。先に年度を
再オープンする必要があります（[**年度の締め**](#年度の締め)画面から、または
`iris reopen`）。

仕訳帳の**削除済み**には、削除された仕訳が、誰がいつ削除したかとともに
一覧で表示されます。削除しても記録は消えず、履歴に残ります。過去の版をダウンロードして
確認できます。復元は、権限のあるローカル・CLI 操作で行ってください。

## レポート

どのレポートも、日付（または基準日）で絞り込め、CSV に書き出せます。損益計算書と
貸借対照表には「残高ゼロの勘定を非表示」の切り替えもあります。

- **総勘定元帳** — 科目を選ぶと、その期間の元帳を紙の元帳と同じ並びで表示します。
  列は、日付・摘要・相手勘定・取引先・借方・貸方・借/貸・残高です。期首残高の行を
  加えることもできます。
  - 摘要には明細行のメモを表示します。メモがない行は、仕訳の説明本文の1行目です。
  - 相手勘定は、仕訳の反対側の科目です。反対側の科目が複数あるときは「諸口」と
    表示します。「諸口」をクリックすると、反対側の明細行と、同じ側のほかの明細行を
    確認できます。帳簿の期首残高の仕訳では「前期繰越」と表示します。
  - 残高は常に0以上の数で表示し、借方残高か貸方残高かは借/貸の列で示します。
  - 絞り込みで行を隠していなければ、月ごとに月計と累計の行が入ります。累計は、
    表示期間が年度の途中から始まっていても、年度の初めから数えます。
  - 印刷には「諸口」などの表示名だけが出ます。CSV には、その内訳も含まれます。
  - 親の科目を選ぶと、その下の科目を1つの元帳にまとめ、補助科目の列を付けて
    表示します。損益計算書・貸借対照表のグループ行をクリックしても同じです。
- **残高試算表** — 基準日時点の残高。「期間」に切り替えると、科目ごとの前期繰越・期間の借方・
  貸方・残高を表示します（期首残高の仕訳は前期繰越に入ります）。借方≠貸方なら警告。
- **損益計算書** — 期間の収益・費用を小計と純利益とともに。勘定科目表で科目に区分を
  付けると、売上高、売上原価、売上総利益、販売費及び一般管理費、営業利益、その他の
  収益・費用、税引前当期純利益、当期純利益の順に並びます。区分のない科目は当期純利益の
  直前に置きます。
- **貸借対照表** — 基準日時点の資産・負債・資本。区分を付けると、資産と負債をそれぞれ
  流動と固定に分け、事業主の科目は最後に別の行で示します。
- 損益計算書と貸借対照表の**前期と比較**で、前期の列を加えます。損益計算書は1年前の
  同じ月々、貸借対照表は1年前の同じ月の月末残高です。数字は帳簿の
  `config/prior-year.yaml` から取ります。前期の帳簿で `iris yearend` を実行すると
  書き込まれます。
- **月次推移表** — 期間の各月を横に並べます。月ごとの収益・費用と当期純利益、続いて
  各月末の資産・負債・純資産。区分ごとに合計の行があります。各月末の部分は、貸借対照表と
  同じく、年度初めからの当期純利益の行と、負債・純資産合計の行で終わります。
  負債・純資産合計は資産合計と一致するはずで、一致しない月があれば警告を表示します。区分を付けると、各月も損益計算書・貸借対照表と同じ
  行で並びます。
- **キャッシュ・フロー** — 期間のキャッシュ・フロー計算書です。期首の現金、営業・投資・
  財務の活動ごとの収入と支出、分類できない仕訳（区分なし）、期末の現金を並べます。
  区分を使わない勘定科目表では、活動に分けず、相手の科目ごとの収入と支出を一覧にします。
  勘定科目表で現金とした科目を対象とし、ない場合は付け方を案内します。

レポートは、初期状態で帳簿の会計年度（`config/book.yaml` の `fiscal_year`）の初日から
今日までを表示します。今日が年度の外にある場合は、年度の範囲に合わせます。年度が
終わったあとなら年度の末日までを、年度が始まる前なら初日だけを表示します。
**仕訳**一覧は帳簿の年度を通年で表示するので、年度の後半に日付を入れた仕訳も見えます。
ほかの期間は日付を変えて表示してください。

レポートに載るのは**記帳済**の仕訳だけです。数値を最後に計算した時刻は、
レポートに表示される注記で確認できます。まだレポートに含まれていない下書きが
あるときは、そのことを知らせるバナーが表示されます。

## 勘定科目

**勘定科目**ページは、勘定科目表を種別（資産 / 負債 / 資本 / 収益 / 費用）ごとに
表示します。科目をクリックすると、いま作業している会計年度の今日までの元帳
（または任意の範囲）が開き、日付フィルタ適用時は期首残高も表示されます。

## 証憑

**証憑**の画面では、`raw/` にあるすべての元資料を見られます。左でファイルを選ぶと、
右に内容が表示されます。画像、PDF、表として読み込んだ CSV、テキストに対応しています。
**参照元の仕訳**には、その資料を参照している仕訳が表示されます。領収書から、それを
計上した仕訳へ直接移動できます。仕訳から資料へのリンクと合わせて、監査人は仕訳と
元資料のあいだをどちらの方向にもたどれます。

## ノート

**ノート**の画面では、`notes/` にあるすべての Markdown ファイルを読めます。作業ノート、
方針、todo、AI のパースキャッシュなどです。ここでは編集できません。パースキャッシュ
には、もとの資料（証憑の画面）へ戻るリンクが付くことがあります。

## アクティビティ

**アクティビティ**は、帳簿全体の訂正・削除の履歴です。すべてのファイル操作
（書き込み・削除・移動）が時系列で並び、実行者・パス・操作で絞り込めます。各行を
展開すると内容の**差分**が見られ、過去の版をダウンロードできます。Web からは現在の
記録を置き換えられません。締め後の変更にはバッジが付きます。

## 年度の締め

**年度の締め**画面には、帳簿の会計年度が表示されます — 仕訳の件数、
締め状態（**未締め** / **締め済み** / **再開中**）、誰がいつ締めたか。
年度を締める画面で、操作できるのは帳簿の**オーナー**です。

- **年度を締める。** プレビューで、締めによってロックされるファイルと、
  残っている下書きを確認できます。下書きが残っている
  年度は締められません — 先に記帳・削除・日付変更で解消してください
  （一覧の各下書きはその仕訳へリンクします）。締めると年度の仕訳と
  `config/`・`assets/`・`filings/`・`compiled/` が**ロック**され、再オープンまで
  変更を受け付けません。`raw/` と `notes/` は引き続き変更できます。
- **年度を再オープンする（ボタンは「再開」）。** 修正のためにロックを解除します。再オープン中に
  ロック対象へ加えた変更は、訂正・削除の履歴に「締め後」として記録され、この印は
  消せません。画面には、締め後に修正されたファイルの数が表示されます。修正が終わったら再度締めてください —
  **履歴**パネルにすべての締めと再オープンが残ります。

同期して締める前に、ローカルで `iris validate` を実行してください。オーバーレイの
検証とレシピの再計算は、帳簿内の定義を使ってローカルで行うものです。クラウドが
確認するのは、会計上の整合性、権限、記帳、締め、版の一致だけです。そのため、
クラウドでプレビューや締めに成功しても、オーバーレイの検証やレシピの再計算に
通ったことにはなりません。

`config/balance-assertions.yaml`（明細などで確かめた残高の記録）がある帳簿では、
プレビューで資料上の残高も照合します。照合には、サーバーが受け入れた同期済みの
仕訳と元資料を使います。記録上の残高、資料上の残高、その差額を確認してください。
金額が一致していても、元資料が不足しているか変更されていれば、未解決として扱います。
その場合は、元の記録をローカルで確認・修正し、同期してからもう一度プレビューします。
この確認に通るまで、サーバーは締めを拒否します。

同期したあとも、元資料についてのサーバー側のデータが不足している、または古いと
表示される場合は、管理者による再構築が必要です。締めを繰り返しても解消しません。
なお、ハッシュの一致が示すのは、資料が同じファイルであることだけです。資料から
金額を正しく書き写したことや、金融機関が発行した資料であることまでは証明しません。

会計ビューのある帳簿を締めるには、宣言したすべてのビューが現在の入力に対して
承認済みであること、元の取引に下書きが残っていないことが必要です。プレビューには、
締めで固定する計算結果が表示されます。締めると、計算結果と、参照している元資料が
ロックされます。それ以外の `raw/` のファイルは、締めたあとも受け取れます。

締めで削除されるものはありません。年度のファイルは帳簿にそのまま残ります。

1つの帳簿は1会計年度分です。翌年度は独立した帳簿として始まります。CLI の
[`iris yearend`](cli-reference.md#iris-yearend) で作成し、**帳簿一覧** に
この帳簿と並んで表示されます。アクセスできるメンバーも同じです。
同じ名前の翌年度の帳簿が帳簿一覧 にあれば、この画面はコマンドの代わりに
その帳簿へのリンクを表示します。

同じ流れは CLI からも行えます（`iris seal`、`iris reopen`）—
[年度締め](records-and-year-end.md#年度締め)を参照。オーナー以外の
メンバーには、同じ年度一覧が読み取り専用で表示されます。

## 設定 — あなたの設定と帳簿の設定

設定は「何に効くか」で2つに分かれます。右上の**歯車アイコン**、または
**アバターメニュー → 設定**から開けます。

**あなたの設定**（アバターメニュー → 設定）には、帳簿ではなくあなた自身に
属するものが集まります。どこからでも開けます — 帳簿の外にいるときも同じです。
設定は項目ごとに分かれています。左の一覧（スマートフォンでは上に並ぶボタン）から
項目を選んでください。開いている項目はアドレスに残るので、ブックマークもできます。

- **ログインとセキュリティ**
  - **パスワードの変更** — 現在のパスワードと新しいパスワードを入力します。
    変更後は、ブラウザ・CLIのセッション、APIトークン、連携アプリのアクセスが
    無効になります。新しいパスワードでログインし、ツールを再接続してください。
  - **ログイン用メールアドレス** — 新しいアドレスに届く確認コードで変更を確定します。
    確認が終わるまでは、現在のアドレスでログインやパスワードの再設定ができます。
    ページを再読み込みした場合は「確認コードをすでに受け取っている」から続けられます。
  - **アカウントのセキュリティ** — すべての端末からサインアウトし、APIトークン、
    CLIセッション、接続済みアプリ、ログイン待ちの承認を無効にします。
    確認後は再ログインとツールの再接続が必要です。端末や認証情報を紛失した
    おそれがあるときに使ってください。
  - **アカウントを閉鎖** — 取り消せない操作です。必要なデータを保存し、自分が作成した
    帳簿とオーナー権限を持つクラウド上の帳簿を先に削除してください。一度ログアウトし、
    ログインし直してから5分以内に、メールアドレスを入力して閉鎖を確定します。
    個人設定、個人の価格データ、共有帳簿へのアクセス、ログイン情報を削除します。
    端末上のファイルや他の人が所有する共有帳簿は残ります。帳簿の履歴、削除済み帳簿の
    保持期間、セキュリティ記録にはプライバシーポリシーが適用されます。削除が完了して
    いない場合は、表示された参照番号をサポートの非公開窓口にお知らせください。
    閉鎖したアカウントは再開できません。
- **表示**
  - **言語** — 画面を English と 日本語 で切り替え。
  - **外観** — ライト / ダーク / システムに合わせる。
- **集計通貨** — 純資産など、複数の帳簿をまたぐ集計に使う通貨。
- **価格履歴** — 記録した価格と為替レートの一覧。単位・通貨・年で絞り込み、
  ページを送って確認できます。**価格を記録**で追加し、各行の**修正**で価格や
  出典を直せます。
- **帳簿** — 参加しているすべての帳簿と役割の一覧。各行からその帳簿の
  設定ページを開けます。
- **AI アシスタント**
  - **AI をつなぐ** — リモートコネクタの URL とセットアップ手順。
    [外出先の AI から帳簿へ](remote-connector.md) を参照。
  - **接続中のアプリ** — リモートコネクタ経由で接続した AI アプリの一覧。
    **接続解除**ボタンでアクセス権を取り消せます。
- **アクセストークン**
  - **パーソナルアクセストークン** — CLI や連携用のトークンを作成。

**帳簿の設定**（帳簿の中でサイドバー → 設定）には、その帳簿に属するものが
集まります。上の帳簿一覧からも1クリックで開けます。

- 帳簿の **ID と会計年度**。
- **記帳承認**（帳簿オーナーのみ） — オンにすると、CLI や AI からの記帳と、
  記帳済の仕訳の変更を、サーバーが拒否します（`APPROVAL_REQUIRED`）。記帳するには、
  Web で下書きの**仕訳のテキスト**を確認して承認します。現在の Web でできるのは
  承認だけです。そのため、この設定がオンの間は、記帳済の仕訳を訂正することも、
  下書きに戻すこともできません。勘定科目表の変更のうち、記帳済の明細を別の
  勘定科目へ移すことになるもの（削除した科目の移行や、旧名を別名として残す変更）も、
  同じように拒否されます。この設定を変更できるのは帳簿オーナーだけで、変更は
  このページで行います。

- **メール取り込み** — 帳簿の受信アドレス、許可する送信者リスト、隔離メールの
  一覧（「送信者を許可」ショートカット付き）。
  [メールで書類を取り込む](email-inbox.md) を参照。
- **権限**（帳簿オーナーのみ） — 誰がどの役割でアクセスできるかを管理し、
  メールで新メンバーを招待。まだ承認されていない招待も表示されます。下記参照。
- **この帳簿から抜ける**（オーナー以外のメンバー） — 自分のアクセス権を外します。
  下記参照。
- **危険な操作**（帳簿オーナーのみ） — 帳簿をクラウドから削除します。下記参照。

### 帳簿を削除する

帳簿の**オーナー**は、帳簿の設定 → **危険な操作** からクラウド上の帳簿を削除できます。
削除はあえて Web 限定の操作にしてあります。ブラウザでのサインインと、帳簿名の
正確な入力が必要です。CLI コマンド・トークン・AI アシスタントからは、どの
アクセスレベルでも実行できません。

削除すると、こうなります。

- 帳簿は**全メンバーから即時に**見えなくなります — Web アプリ、CLI、接続中の
  AI アプリのすべてで。
- 削除後**30 日間**は、データがサーバーに残ります（画面には表示されません）。
  誤って削除した場合は、この期間内に
  [Discordコミュニティ](https://discord.gg/wZDsv9gyb9)で復元を相談してください。
  30日を過ぎると、仕訳・ファイル・訂正・削除の履歴を含むサーバー上の全データが
  **完全に消去**されます。締め済みの会計年度がある
  場合はダイアログが警告します。削除すれば締め済み期間の記録も監査証跡も
  失われるので、残すべきものは先に書き出してください。
- **ローカルコピーには一切触れません。** パソコンにある帳簿のフォルダは、
  すべてのファイルを含めてそのまま残ります。そこで `iris sync` を実行すると帳簿が削除された
  ことが報告され、ローカルで作業を続ける方法や新しいクラウド帳簿への接続方法が
  案内されます。
- 帳簿の受信アドレス宛のメールは破棄され、発行済みのアップロードリンクは
  無効になります。

### 共同作業と役割

帳簿オーナーは**役割**で他者にアクセスを付与します。

| 役割 | できること |
| --- | --- |
| **オーナー** | メンバーと役割の管理を含むすべて。 |
| **記帳担当** | 仕訳の作成・編集。 |
| **レビュアー** | 読み取り専用のレビュー。 |

権限セクションからメールで招待します。招待された人が Web アプリで承認するまで、
アクセス権は付与されません。それまで権限の一覧には「招待中（未承認）」と表示され、
そこで招待を取り消せます。すでに IrisBooks のアカウントがある人には、招待が届いて
いることを知らせるメールが、新しい人には仮パスワード付きのアカウント案内メールが
届きます。メンバーの役割の変更・取消はいつでも行えます。（オーナーは CLI からも
権限を管理できます — [`iris api grants`](cli-reference.md) を参照。）

招待を承認できるのは招待された本人だけで、操作は Web アプリに限られます。CLI の
コマンド、トークン、AI アシスタントが代わりに承認・辞退することはできません。

メンバーはいつでも帳簿から抜けられます。帳簿の設定 → **この帳簿から抜ける** を
選んでください。オーナーは権限の一覧から自分を外します。最後のオーナーは抜けられ
ません。先に別の人をオーナーにするか、帳簿を削除してください。権限の一覧では、
唯一のオーナーにその旨が表示され、役割の変更と取り消しのボタンは出ません。

これが**事業主と税理士**が帳簿を共有する仕組みです。オーナーが税理士を招待（または
税理士がオーナーを招待）します。両者が自分の AI と同期したファイルで作業し、
同じクラウド帳簿を共有できます。Web は閲覧・レビュー・権限に応じた承認に使い、
ファイルでの作業を補います。

### パーソナルアクセストークン（PAT）

PAT は、スクリプトや CLI で使う長期間有効な認証情報です。権限の範囲は役割
（**viewer / bookkeeper / full**）で決まります。あなたの設定（アバターメニュー →
設定）で作成します。値が表示されるのは作成時の**一度だけ**なので、その場でコピーして
`IRIS_API_TOKEN` に設定してください。

トークンは、90日間使わないと失効します。使うたびに期限が延びますが、発行から1年を
超えては延びません。最終使用時刻と有効期限は設定画面で確認できます。トークンは、
いつでもすぐに失効させられます。この設定画面のほか、CLI の `iris api token list` /
`iris api token revoke` も使えます。フルアクセスの PAT でもほかのトークンを
失効させられますが、トークンを作成できるのは Web だけです。

作成時に、アクセスを許可する帳簿を選びます。トークンの権限は、各帳簿でのあなた自身の
権限を超えません。一覧やレポートに含まれるのも、許可した帳簿だけです。
**帳簿の作成を許可する**を選ぶと、このトークンで作成した帳簿（翌年度の帳簿を含む）にも、
同じ操作権限でアクセスできます。ほかの方法で作成した帳簿は対象になりません。
翌年度の帳簿を作る（`iris yearend`）には、フルの操作権限と、元の帳簿のオーナー権限が
必要です。帳簿を制限したフルのトークンで一覧・失効できるのは、そのトークン自身だけです。
ほかのトークンは Web で管理します。帳簿を制限せずに作成した既存のトークンは、
これまでどおりのアクセス範囲のままです。範囲を絞るには、失効させて作り直してください。

## 税理士向け — 日々の形

顧客ごとに作業フォルダを分け、AI がアクセスできるファイルやツールもその顧客に
限定します。その環境で AI と仕訳を作成・検証してください。フォルダ・ツール・認証情報の範囲は
[ファイルでの作業手順](cli-and-llm.md)を参照してください。
Web アプリは、複数の顧客のレビューを整理するために使います。

- **帳簿一覧**は顧客の一覧として使えます。各帳簿（顧客ごと・会計年度ごとに
  1冊）の年度、下書き件数、最終アクティビティに加え、**年度の締め**列がその年度の
  締め状態 — 締め済み / 再開中 / **締め可** / 「下書き N 件」 — を表示します。
  年度末にはこの列がそのまま作業リストになり、各バッジからその帳簿の年度の締め
  画面へ直接移動できます。
- 顧客の帳簿に切り替えて仕訳をレビュー・承認し、**アクティビティ**ログで
  スタッフの作業を確認し、レポートを実行します。
- **PAT** + `iris api …` による権限のある帳簿の一括処理は、顧客ごとの
  AI セッションとは別に実行します。
- 年度末には**年度の締め**画面（または CLI）で各顧客の会計年度を
  締めます —
  [年度締め](records-and-year-end.md#年度締め) を参照。

クラウドの権限は帳簿ごとに付与します。1社で複数年度の帳簿を持つ場合も、
その顧客のファイルは専用の作業フォルダにまとめます。ダッシュボードの
**合算損益**は、初期状態では顧客の帳簿も含め、アクセスできるすべての帳簿を
集計します。帳簿の選択欄で集計対象を選んでください。**純資産**は、自分で作成し
所有している帳簿だけを既定の対象とします。招待された帳簿は、オーナーとして招待
された場合も含め、設定タブで追加したときだけ集計します。

次へ: [記録の履歴と年度締め](records-and-year-end.md)。

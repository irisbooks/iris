# Web アプリを使う

Web アプリは、事業主と税理士がレポートの閲覧、仕訳のレビュー、権限に応じた承認、
履歴の確認、クラウドのアクセス管理に使う画面です。税理士の記帳作業にも、
顧客ごとに作業環境を分けて[自分の AI と帳簿ファイルで作業する方法](cli-and-llm.md)を
勧めます。Web アプリはクラウド上の帳簿コピーを使うため、サインインと
オンライン接続が必要です。

## サインイン

アカウントはメールアドレス + パスワードで作成します。サインイン画面では次ができます。

- メールと登録済みパスキー、またはパスワードで**ログイン**。
  認証アプリを設定すると、パスワードでのログインには 6 桁のコードも必要です。
  パスキーを使えない場合や操作をキャンセルした場合は、パスワードと認証アプリで
  ログインできます。
- （受付中なら）**新規登録** — メールとパスワードを送信し、届いた確認コードで
  認証。
- 「パスワードをお忘れですか」から**パスワード再設定** — コードを受け取り、新しい
  パスワードを設定。

これらの画面の右上には言語切替（「日本語」/「English」表記）があり、
ブラウザの言語判定が違っていた場合に切り替えられます。`.io` サービスの
確認コード・再設定コード・招待メールは、現在 Cognito 標準の英語で届きます。
アプリは日本語と英語で利用できます。

税理士に帳簿へ招待された場合は、招待された正確なメールアドレスで登録（または
ログイン）すれば、帳簿はすでにそこにあります。

**CLI 認可**ページもあります。`iris api login` を実行するとブラウザがここを開き、
コマンドラインツールを認可します。自分のメールと想定どおりのツールであることを
確認して承認してください。

`iris api login --device` の場合は、表示された IrisBooks の URL を自分の
スマートフォンで開きます。サインインしてリクエスト番号を入力し、アカウント・権限・
注意書きを確認してから承認してください。自分で開始したリクエストだけを承認し、
表示されるデバイス名は未確認の情報として扱ってください。パスワード・認証コード・
パスキーを VM に渡す必要はありません。承認後、VM 専用の CLI セッションが発行されます。

### パスキーと認証アプリのバックアップ

アバターメニュー → 設定 → アカウントのセキュリティで、まず認証アプリを設定します。
QR を読み取るか設定キーをコピーし、コードを入力して確認してください。
認証アプリのバックアップを確保したら、自分のデバイスでパスキーを追加できます。
予備のパスキーをもう一つ登録することもできます。パスキーでのログインには
デバイスの生体認証や PIN を使い、認証アプリのコードを追加で入力する必要はありません。
同じ画面で認証アプリの入れ替えやパスキーの削除ができます。

設定変更の前に求められた場合は、もう一度サインインしてください。変更後は既存の
ブラウザ・CLI・API トークン・コネクターのアクセスが取り消されるため、必要な場所で
再ログイン・再接続します。変更の完了に失敗した場合は、完了を再試行するボタンを
使ってください。既存ユーザーは任意のタイミングで設定できます。パスワードを再設定しても
認証アプリの保護は解除されません。すべての認証手段を失った場合のセルフサービス復旧は
未対応です。パスキーを使い始める前に、使えるバックアップを確保してください。

## レイアウト

サイドバーは、帳簿を横断する画面でも個別の帳簿でも使えます。

- **帳簿を横断**には、集計を見るための**ダッシュボード**と**純資産**があります。
- **帳簿一覧**には、各帳簿の名前と会計年度が並びます。横断画面から帳簿を開くと
  その帳簿の概要に移動します。別の帳簿へ切り替える場合は、仕訳帳やレポートなど
  同じ種類の画面へ移り、元の帳簿のフィルターやファイル選択は引き継ぎません。
  矢印は画面を切り替えずにメニューを展開します。一度に展開する帳簿は一つで、
  概要・仕訳帳・アクティビティ、4種類のレポート、ファイル・勘定科目・ノート・
  年度の締め・帳簿の設定を選べます。
- **締め済みの帳簿**には、締め済みとアーカイブ済みの帳簿をまとめています。
  その帳簿の URL を直接開くと、グループとメニューが自動で展開されます。
- **帳簿の管理**から一覧ページ、**新しい帳簿を追加**から作成画面を開けます。
  帳簿が1冊の場合も利用できます。

上部バーには「ダッシュボード」「純資産」「帳簿の管理」「設定」「新しい帳簿を追加」
など、現在の画面名が表示されます。帳簿の中では帳簿名と会計年度が表示され、
年度は**年度の締め**へのリンクです。スクロールしても上部バーは表示され続け、
サイドバーやスマートフォンのメニューはその直下に表示されます。スマートフォンでは、
左上のメニューボタンから同じ操作を行えます。

右上の**アバター**からは、どこにいてもアカウントメニューが開けます。
**設定**（後述）、言語切替、ログアウトです。言語の項目は常に*もう一方の*
言語名（「日本語」/「English」）で表示されるので、読めない言語の画面に
なってしまっても戻り道は読める状態で残ります。配色テーマを含め、それ以外は
すべて設定ページにあります。

画面ごとに URL があり、ダッシュボードは `/app/`、純資産は `/app/networth`、
帳簿の一覧は `/app/books`、個別の帳簿は `/app/b/<book-id>/...` です。
ブックマークしたり、別々のブラウザータブで開いたりできます。表示する帳簿は
URL で決まり、前に開いた帳簿には左右されません。既存のレポートのフィルターや
ファイル選択も URL に保持されます。

## ダッシュボード

帳簿を横断して、純資産・連結損益・上位変動要因・未転記の仕訳を確認するホーム
画面です。帳簿が1冊でも表示します。個別の帳簿の損益フロー図と貸借対照表の
構成は、その帳簿の**概要**で確認できます。サイドバーで帳簿を開いても集計への
算入設定は変わりません。集計する帳簿は各レポートの設定で選びます。

帳簿の通貨が揃っていない場合は、基軸通貨を設定してください
（`iris api config set --base-currency JPY`）。連結損益に**換算レート**が表示され、
他の通貨ごとに、使用したレートとその記録日が並びます。各レートは編集でき、
別の値を入力すると合計がその場で再計算されます。この編集は表示にのみ反映され、
保存されません。レートを残すには `iris price add --unit USD --price 155` で
記録してください（純資産で保有を評価するのと同じ価格ストアです）。

レートが未記録の通貨は入力欄が空になり、その通貨の帳簿は合計に含めず個別に
表示します。レートの記録漏れが数値を静かに変えるのではなく、目に見えるように
するためです。

## 仕訳

**仕訳**は取引一覧です。ここから次ができます。

- **絞り込み・検索** — 日付範囲、取引先、フリーテキスト、ステータス（記帳済 /
  下書き / 締切済 …）、金額（等しい / 超 / 未満）。
- 絞り込んだ一覧を CSV に**エクスポート**。
- 仕訳を**開いて**詳細を見る — 日付、取引先、ステータス、タグ、添付された元資料
  （クリックで資料へ）、借方/貸方と合計を持つ明細表、説明本文。
- **新規仕訳**ボタンで作成 — 日付・取引先・明細・タグ・添付を入力して保存。
- 既存の仕訳をその場で**編集・削除**。削除はソフト削除です。仕訳は
  **削除済み**ビューに移り、そこから復元できます。
- **下書きを記帳** — 詳細ページのワンクリック**記帳**ボタンで、下書きを
  記帳済みにできます（借方と貸方が一致すると押せるようになります）。下書きは、
  記帳するまで各種レポートや残高に反映されません。まとめて記帳するには — 例えば
  [リモートコネクタ](remote-connector.md)で作った下書きの束 — 一覧で
  チェックを入れて**選択した仕訳を記帳**を使います。

### 履歴と「締め後」の警告

仕訳詳細ページの**履歴**パネルには、そのファイルの完全な監査証跡が残ります。
put / delete / move の各操作と、実行者・日時・出所・理由です。締め後に再オープン
された年度で変更された仕訳には、はっきり **「締め後」**バッジが付きます。
これは訂正・削除の履歴を仕訳単位で見るビューです。

日付が**締め済み**会計年度に入っている仕訳は「締切済」と表示され（一覧・
締切済フィルタ・詳細ページ）、編集・削除・記帳はできません。先に年度を
再オープンする必要があります（[**年度の締め**](#年度の締め)画面から、または
`iris reopen`）。

仕訳一覧からの**削除済み**ビューは、ソフト削除された仕訳を、誰がいつ削除したかと
ともに一覧します。削除は消去ではなく記録されます。各行には**復元**アクションが
あり、仕訳を仕訳一覧に戻せます。

## レポート

4種類のレポート。それぞれ日付 / 基準日フィルタ、「残高ゼロの行を隠す」トグル、
CSV エクスポートを備えます。

- **元帳** — 科目を選ぶと、その期間の完全な元帳を表示（任意で期首残高付き）。
- **試算表** — 基準日時点の残高。借方≠貸方なら警告。
- **損益計算書** — 期間の収益・費用を小計と純利益とともに。
- **貸借対照表** — 基準日時点の資産・負債・資本。

レポートは帳簿の会計年度（`config/book.yaml` の `fiscal_year`）を、年度の初日から
今日まで表示します。今日が年度の開始前なら初日まで、終了後なら末日までです。
**仕訳**一覧は帳簿の年度を通年で表示するので、年度の後半に日付を入れた仕訳も見えます。
ほかの期間は日付を変えて表示してください。

レポートに載るのは**記帳済み**の仕訳だけです。「鮮度（freshness）」の注記が、元の
数値が最後に計算された時刻を示し、「未完了」バナーがまだ計上されていない下書きの
存在を知らせます。

## 勘定科目

**勘定科目**ページは、勘定科目表を種別（資産 / 負債 / 資本 / 収益 / 費用）ごとに
表示します。科目をクリックすると、いま作業している会計年度の今日までの元帳
（または任意の範囲）が開き、日付フィルタ適用時は期首残高も表示されます。

## 元資料

**元資料**ブラウザは、`raw/` 配下すべての2ペインビューです。ファイルを選ぶと
インラインで描画されます — 画像、PDF、解析済み CSV テーブル、テキスト。
**引用元**パネルはその資料を参照する仕訳を表示するので、領収書から、それを計上
した仕訳へ直接ジャンプできます。この逆方向のドリルダウンは帳簿の仕訳↔証憑の
監査証跡です — 監査人はどの領収書からも、それを計上した仕訳へ（またその逆へ）
たどれます。

## ノート

**ノート**ブラウザは、`notes/` 配下すべての読み取り専用 Markdown ビューアです —
作業ノート、方針、todo、AI のパースキャッシュ。パースキャッシュは、元資料ブラウザ
内の出所ドキュメントへ戻るリンクを持てます。

## アクティビティ

**アクティビティ**タイムラインは、帳簿全体の監査ログです。帳簿全体のすべての
ファイル操作（put / delete / move）を、実行者・パス・操作で絞り込めます。各行を
展開すると内容の**差分**が見られ、以前のバージョンがあれば **復元**ボタンが出ます。
締め後の変更にはバッジが付きます。これは恒久履歴を帳簿単位で見るビューです。

## 年度の締め

**年度の締め**画面には、帳簿の会計年度が表示されます — 仕訳の件数、
締め状態（**未締め** / **締め済み** / **再開中**）、誰がいつ締めたか。
期間の締めを行う場所で、操作できるのは帳簿の**オーナー**です。

- **年度を締める。** プレビューで、締めによってロックされるファイルと、
  残っている下書きを確認できます。下書きが残っている
  年度は締められません — 先に記帳・削除・日付変更で解消してください
  （一覧の各下書きはその仕訳へリンクします）。締めると年度の仕訳と
  `config/`・`assets/`・`filings/`・`compiled/` が**ロック**され、再オープンまで
  変更を受け付けません。`raw/` と `notes/` は引き続き変更できます。
- **年度を再オープンする。** 修正のためにロックを解除します。再オープン中に
  ロック対象の変更が監査証跡に「締め後」として恒久的に記録され、画面には締め後に
  修正されたファイル数が表示されます。修正が終わったら再度締めてください —
  **履歴**パネルにすべての締めと再オープンが残ります。

プレビューと締めの前に、申告記録がクラウドの現在の記帳済み仕訳とレシピの元データから
再計算できる必要があります。仕訳の修正後に申告記録が古くなった場合や、元データが
使えない場合は、下書き一覧を表示する前にプレビューが失敗することもあります。
申告レシピを正しい入力で再実行し、`iris validate` で検証してから、申告記録と入力を
同期し、プレビューをやり直してください。同期が成功してもクラウドが再計算用データの
不足を報告する場合は、[Discordコミュニティ](https://discord.gg/wZDsv9gyb9)で相談してください。締めを繰り返しても解消しません。

締めで削除されるものはありません。年度のファイルは帳簿にそのまま残ります。

1つの帳簿は1会計年度分です。翌年度は独立した帳簿として始まります。CLI の
[`iris yearend`](cli-reference.md#iris-yearend) で作成し、**My Books** に
この帳簿と並んで表示されます。アクセスできるメンバーも同じです。

同じ流れは CLI からも行えます（`iris api seal`、`iris reopen`）—
[日本の税務・コンプライアンス](japan-tax-and-compliance.md)を参照。オーナー以外の
メンバーには、同じ年度一覧が読み取り専用で表示されます。

## 設定 — あなたの設定と帳簿の設定

設定は「何に効くか」で2つに分かれます。入口はひとつで、右上の
**アバターメニュー → 設定**です。

**あなたの設定**（アバターメニュー → 設定）には、帳簿ではなくあなた自身に
属するものが集まります。どこからでも開けます — 帳簿の外にいるときも同じです。

- **パスワードの変更** — 現在のパスワードと新しいパスワードを入力します。
  変更後は、ブラウザー・CLIのセッション、APIトークン、連携アプリのアクセスが
  無効になります。新しいパスワードでログインし、ツールを再接続してください。
- **ログイン用メールアドレス** — 新しいアドレスに届く確認コードで変更を確定します。
  確認が終わるまでは、現在のアドレスでログインやパスワードの再設定ができます。
  ページを再読み込みした場合は「確認コードをすでに受け取っている」から続けられます。
- **アカウントを閉鎖** — 取り消せない操作です。必要なデータを保存し、自分が作成した
  帳簿とOwner権限を持つクラウド上の帳簿を先に削除してください。一度ログアウトし、
  ログインし直してから5分以内に、メールアドレスを入力して閉鎖を確定します。
  個人設定、個人の価格データ、共有帳簿へのアクセス、ログイン情報を削除します。
  端末上のファイルや他の人が所有する共有帳簿は残ります。帳簿の履歴、削除済み帳簿の
  保持期間、セキュリティ記録にはプライバシーポリシーが適用されます。削除が完了して
  いない場合は、表示された参照番号をサポートの非公開窓口にお知らせください。
  閉鎖したアカウントは再開できません。
- **言語** — 画面を English と 日本語 で切り替え。
- **外観** — ライト / ダーク / システムに合わせる。
- **帳簿** — 参加しているすべての帳簿と役割の一覧。各行からその帳簿の
  設定ページを開けます。
- **アカウントのセキュリティ** — すべての端末からサインアウトし、APIトークン、
  CLIセッション、接続済みアプリ、ログイン待ちの承認を無効にします。
  確認後は再ログインとツールの再接続が必要です。端末や認証情報を紛失した
  おそれがあるときに使ってください。
- **パーソナルアクセストークン** — CLI や連携用のトークンを作成。
- **AI をつなぐ** — リモートコネクタの URL とセットアップ手順。
  [外出先の AI から帳簿へ](remote-connector.md) を参照。
- **接続中のアプリ** — リモートコネクタ経由で接続した AI アプリの一覧。
  **接続解除**ボタンでアクセス権を取り消せます。

**帳簿の設定**（帳簿の中でサイドバー → 設定）には、その帳簿に属するものが
集まります。上の帳簿一覧からも1クリックで開けます。

- 帳簿の **ID と会計年度**。
- **記帳承認**（帳簿オーナーのみ） — オンにすると、記帳と、記帳済み仕訳の
  編集・削除・下書きへの差し戻しは、この Web アプリからのみ行えます。AI
  アシスタントと CLI は下書きの作成・編集を続けられますが、記帳済み仕訳に
  触れる操作は拒否されます（`APPROVAL_REQUIRED`）。すべての仕訳を自分の手で
  確かめてから帳簿に載せたいときに使ってください。この設定を変えられるのは
  オーナーだけで、しかもこのページからだけです。CLI やトークンから外せないのは
  意図的で、AI アシスタントが自分でこのゲートを開けられないようにしてあります。
- **メール取り込み** — 帳簿の受信アドレス、許可する送信者リスト、隔離メールの
  一覧（「送信者を許可」ショートカット付き）。
  [メールで書類を取り込む](email-inbox.md) を参照。
- **権限（Grants）**（帳簿オーナーのみ） — 誰がどの役割でアクセスできるかを管理し、
  メールで新メンバーを招待。下記参照。
- **危険な操作**（帳簿オーナーのみ） — 帳簿をクラウドから削除します。下記参照。

### 帳簿を削除する

帳簿の**オーナー**は、帳簿の設定 → **危険な操作** からクラウド上の帳簿を削除できます。
削除はあえて Web 限定の操作にしてあります。ブラウザでのサインインと、帳簿名の
正確な入力が必要です。CLI コマンド・トークン・AI アシスタントからは、どの
アクセスレベルでも実行できません。

削除すると、こうなります。

- 帳簿は**全メンバーから即時に**見えなくなります — Web アプリ、CLI、接続中の
  AI アプリのすべてで。
- **30 日間**はサーバー上に見えない状態でデータが残り、誤操作なら期間内に
  [Discordコミュニティ](https://discord.gg/wZDsv9gyb9)で復元について相談してください。その後、仕訳・ファイル・訂正・削除の履歴を
  含むサーバー上の全データが**完全に消去**されます。締め済みの会計年度がある
  場合はダイアログが警告します。削除すれば締め済み期間の記録も監査証跡も
  失われるので、残すべきものは先に書き出してください。
- **ローカルコピーには一切触れません。** お使いのコンピュータ上のクローンは
  すべてのファイルを保持します。そこで `iris sync` を実行すると帳簿が削除された
  ことが報告され、ローカルで作業を続ける方法や新しいクラウド帳簿への接続方法が
  案内されます。
- 帳簿の受信アドレス宛のメールは破棄され、発行済みのアップロードリンクは
  無効になります。

### 共同作業と役割

帳簿オーナーは**役割**で他者にアクセスを付与します。

| 役割 | できること |
| --- | --- |
| **Owner** | メンバーと役割の管理を含むすべて。 |
| **Bookkeeper** | 仕訳の作成・編集。 |
| **Reviewer** | 読み取り専用のレビュー。 |

権限セクションからメールで招待し、役割の変更・取消はいつでも行えます。（オーナーは
CLI からも権限を管理できます — [`iris api grants`](cli-reference.md) を参照。）

これが**事業主と税理士**が帳簿を共有する仕組みです。オーナーが税理士を招待（または
税理士がオーナーを招待）します。両者が自分の AI と同期したファイルで作業し、
同じクラウド帳簿を共有できます。Web は閲覧・レビュー・権限に応じた承認に使い、
ファイルでの作業を補います。

### パーソナルアクセストークン（PAT）

PAT はスクリプトや CLI 用の長期間有効な認証情報で、役割（**viewer /
bookkeeper / full**）で権限の範囲が決まります。あなたの設定（アバターメニュー →
設定）で作成すると、値が**一度だけ**表示されます。二度と表示されないので、その場で
コピーして `IRIS_API_TOKEN` に設定してください。トークンは 90 日使わないと失効
します（使うたびに延び、発行から最長 1 年）。最終使用時刻と
有効期限が表示され、いつでも即座に失効できます — この設定画面のほか、CLI の
`iris api token list` / `iris api token revoke` からも失効できます（フルアクセス
PAT でも失効可能。作成は Web のみ）。作成時にアクセスを許可する帳簿を選びます。
各帳簿でのあなたの権限が上限となり、一覧やレポートにも許可した帳簿だけが含まれます。
**帳簿の作成を許可する**を選ぶと、このトークンで作成した帳簿には、翌年度の帳簿も
含め、同じ操作権限でアクセスできます。他の方法で作成した帳簿は含まれません。
年度の引継ぎには Full と引継ぎ元の Owner 権限が必要です。帳簿を制限した Full
トークンで一覧・失効できるのは自分自身だけで、他のトークンは Web で管理します。
既存の制限なしトークンのアクセス範囲は変わりません。絞る場合は失効して作り直してください。

## 純資産

**純資産**は、帳簿が持っているものから負っているものを差し引いた額を、帳簿を
またいで合計します。現金・売掛金・固定資産・借入金は帳簿に記録した金額で、
外貨・暗号資産・株式・貴金属は記録した価格で評価します。画面には合計、前月比、
トレンドライン、最大の変動要因、構成内訳が並びます。勘定科目表で `owner: true`
を付けた科目（事業主貸・事業主借）は含めません。事業ではなく事業主自身のお金だから
です。**設定**タブでは、連結合計に含める帳簿を選べます。

帳簿は自分の会計年度の月だけを受け持つので、トレンドラインはある年度の帳簿から
翌年度の帳簿へ、二重に数えることなくつながります。帳簿の年度が終わると、翌年度の
帳簿ができるまではその帳簿を集計に含めず、*年度終了* として一覧します。
[`iris yearend`](cli-reference.md#iris-yearend) を実行すると戻ります。

これは監査済みの数値ではなく、ベストエフォートの「いま自分はどうか」の目安です。
価格が未記録の単位は簿価で数え、一覧に出すので、何に価格を付ければよいかが
分かります。IrisBooks が価格を代わりに取ってくることはありません。為替レートも
同じです。`iris price add` で自分で記録してください。

## 税理士向け — 日々の形

顧客ごとに作業フォルダを分け、AI がアクセスできるファイルやツールもその顧客に
限定します。その環境で AI と仕訳を作成・検証してください。フォルダ・ツール・認証情報の範囲は
[ファイルでの作業手順](cli-and-llm.md)を参照してください。
Web アプリは、複数の顧客のレビューを整理するために使います。

- **My Books** はクライアント一覧です。各帳簿（クライアントごと・会計年度ごとに
  1冊）の年度、下書き件数、最終アクティビティに加え、**年度の締め**列がその年度の
  締め状態 — 締め済み / 再開中 / **締め可** / 「下書き N 件」 — を表示します。
  年度末にはこの列がそのまま作業リストになり、各バッジからその帳簿の年度の締め
  画面へ直接移動できます。
- クライアント帳簿に切り替えて仕訳をレビュー・承認し、**アクティビティ**ログで
  スタッフの作業を確認し、レポートを実行します。
- **PAT** + `iris api …` による権限のある帳簿の一括処理は、顧客ごとの
  AI セッションとは別に実行します。
- 年度末には**年度の締め**画面（または CLI）で各クライアントの会計年度を
  締めます —
  [日本の税務・コンプライアンス](japan-tax-and-compliance.md) を参照。

クラウドの権限は帳簿ごとに付与します。1社で複数年度の帳簿を持つ場合も、
その顧客のファイルは専用の作業フォルダにまとめます。ダッシュボードの
**連結損益**は、初期状態ではクライアント帳簿も含め、アクセスできるすべての帳簿を
集計します。帳簿の選択欄で集計対象を選んでください。**純資産**は自分が所有する
帳簿だけを既定の対象とし、招待された帳簿は設定タブで追加した場合に集計します。

次へ: [日本の税務・コンプライアンス](japan-tax-and-compliance.md)。

# このパソコンで帳簿を開く（iris view）

`iris view` は、パソコンにある帳簿のファイルをそのまま読み込み、Web アプリと
同じ画面で開きます。レポートや仕訳を見るほか、下書きの記帳、下書きの修正、
新しい仕訳の作成、記帳済の仕訳の訂正ができます。アカウントもネットワークも
不要で、何もアップロードしません。変更はファイルへの通常の編集として保存され、
クラウドにリンクした帳簿なら次の同期でクラウドに反映されます。

## 開き方

```bash
iris view                           # いま作業している帳簿
iris view ~/IrisBooks/shop-2026     # 帳簿を1冊
iris view --books-dir ~/IrisBooks   # このフォルダの帳簿をすべて
```

帳簿のフォルダの中で `iris view` を実行すると、その帳簿が開きます。
`--books-dir` を付けると、フォルダの直下にある帳簿をすべて開き、それらを
まとめた**ダッシュボード**と**純資産**も表示します。どの帳簿の中でもない場所で
実行すると、前回使ったフォルダを開くか、どのフォルダを開くかを尋ねます。

画面は専用のウィンドウで開きます。使うのは Chrome か Edge で、アドレスバーも
拡張機能もありません。どちらもなければ、いつものブラウザで開きます。`--tab`
を付けると、最初からいつものブラウザで開きます。Mac では、Dock やアプリの
切り替え画面に Google Chrome または Microsoft Edge として表示されます。

`iris view` はすぐに終わります。画面は閉じるまで使えます。フォルダの帳簿が
クラウドとも同期している場合は、上部バーに**ローカルのコピー**と表示されます。
画面に出ているのはローカルのファイルで、変更は次の同期でクラウドのコピーに
反映されます。

## ランチャー

ターミナルや AI を使わずに帳簿を開けるよう、IrisBooks のランチャーを追加できます。

```bash
iris view --add-launcher
```

| システム | 表示される場所 |
| --- | --- |
| macOS | `~/Applications` の **IrisBooks**。Spotlight で探すか、Dock にドラッグします。 |
| Windows | スタートメニューの **IrisBooks**。 |
| Linux | デスクトップのアプリメニューの **IrisBooks**。 |

ランチャーは前回使ったフォルダを開くか、どのフォルダを開くかを尋ねます。
ランチャー自体はフォルダを持たないので、1つのランチャーでどのフォルダも開けます。
最初に開くフォルダを決めておきたいときは、追加するときに指定します:
`iris view --books-dir ~/IrisBooks --add-launcher`。`--tab` を付けると、
ランチャーはいつものブラウザで開きます。

削除するには `iris view --remove-launcher` を実行します。`iris uninstall`
でも削除されます。`iris` を別の場所に移したときは、ランチャーを追加し直して
ください。

## フォルダを選ぶ

上部バーの上にある色付きの帯に、いま開いているフォルダの名前が表示されます。
帯のメニューには次の項目があります。

- **最近使ったフォルダ**：以前に開いたフォルダに切り替えます。
- **フォルダを選ぶ**：システムのフォルダ選択画面を開きます。選択画面がない
  環境では、**フォルダのパス**にパスを入力して**開く**を選びます。
- **色**：緑・青・青緑・紫・赤茶・茶・黄土・墨から選べます。

選ぶのは、1冊の帳簿のフォルダでも、複数の帳簿が入ったフォルダでもかまいません。
どちらなのかは iris が判断します。切り替えると、同じウィンドウで別のフォルダが
開きます。

色は、フォルダをひと目で見分けるためのものです。たとえば顧客ごとの帳簿を
取り違えないように使えます。複数の帳簿が入ったフォルダは、色をそのフォルダの
`.irisbooks/settings.yaml` に保存するので、どこで開いても同じ色になります。
1冊の帳簿の色はこのパソコンに保存します。帳簿のファイルは同期されるためです。
色を決めていないフォルダには、パスから決まる色が付くので、フォルダごとの色は
初めからたいてい違います。色を決めていないフォルダすべてに同じ色を使うなら、
`~/.config/irisbooks/settings.yaml` に `color` を設定します。詳しくは
[帳簿フォルダの価格と設定](cli-reference.md#帳簿フォルダの価格と設定)を
参照してください。

言語と表示テーマはフォルダごとに保存されます。最初は帳簿の言語で開き、
その後は上部バーの言語切り替えに従います。

## 見られる画面

次の画面は [Web アプリ](web-app.md)と同じように使えます。数字は iris が
ファイルから計算します。

- **概要**、**仕訳帳**、各仕訳の詳細。
- 4種類のレポート：**総勘定元帳**、**残高試算表**、**損益計算書**、
  **貸借対照表**。
- **勘定科目**、**証憑**、**ノート**。
- **プラグイン**（このページだけの画面です。下記を参照）。
- フォルダに帳簿が2冊以上あるときは、帳簿をまとめた**ダッシュボード**と
  **純資産**。フォルダ内のすべての帳簿が対象です。

あなたや AI がファイルを変更すると、数秒で画面に反映されます。**集計を実行**
の操作はありません。IrisBooks のどこでも同じく、レポートに載るのは記帳済の仕訳だけです。

クラウドのデータが必要な画面はありません：**アクティビティ**、削除した仕訳、
**年度の締め**、帳簿の設定、仕訳の**履歴**、帳簿の追加。これらは Web アプリで
使ってください。

## 下書きを記帳する

下書きを開いて内容を確認し、**記帳**を選びます。まとめて記帳するときは、
**仕訳帳**で仕訳を選び、**選択した仕訳を確認**を選んでそれぞれを確認してから、
**確認した仕訳を記帳**を選びます。一度に確認できるのは32件までです。

記帳で変わるのは `status: draft` から `status: posted` への書き換えだけで、
`iris post --local` と同じです。同期はしません。クラウドにリンクした帳簿では
「このパソコンで記帳済にしました。次の同期でクラウドに反映されます。」と
表示されます。

次の場合は記帳できず、ファイルは元のまま残ります。

- 開いた後で仕訳が変更された。もう一度確認してから記帳します。
- 同期の実行中。終わってからもう一度お試しください。
- 帳簿が Web アプリで記帳する設定になっている（**記帳承認**がオン）。
- 仕訳の年度が締め済み。先に再オープンします。
- 帳簿がアーカイブ。

記帳承認の設定と締め済みの年度は、帳簿の前回の同期の内容に従います。

## 仕訳を編集する

下書きや記帳済の仕訳のページで**編集**を選びます。**フォーム**でも、ファイルそのものである
**テキスト**でも編集でき、途中で切り替えられます。フォームが変えるのは
あなたが変えた箇所だけで、フォームに表示されないもの（コメント、数量、帳簿の
オーバーレイのフィールドなど）はそのまま残ります。会計ビューがある仕訳は、
テキストでのみ編集できます。

- **入力に合わせて、帳簿のオーバーレイが計算できるものを計算します。**空欄に
  した金額などが対象で、[`iris journal complete`](cli-reference.md#iris-journal-complete)
  と同じです。
  計算結果は空欄の中に破線の枠付きで表示され、売却益のようにオーバーレイが
  追加する明細は、ほかの明細の下に表示されます。**記入**を選ぶと、まとめて
  入力されます。追加したまま何も入力していない行も取り除きます。
  **計算方法**を開くと、計算された金額ごとに計算の過程を確認できます。売却の
  原価はそのもとになった過去の取得分から、貸借を一致させる金額はほかの明細
  から示します。オーバーレイが自ら定めた金額は、オーバーレイが示す理由か、続けて表示するオーバーレイ
  自身の説明で確認できます。帳簿の
  オーバーレイ同士で計算結果が異なるときは、両方の結果が並んで表示されます。
  どちらかを選ぶと、編集を続けてもその選択が保たれます。
  計算できないときは、合計の下に理由を表示します。金額を確認して**保存**を
  選ぶまで、何も保存されません。金額が空欄のまま保存された仕訳も、
  下書き・記帳済を問わずここで開いて記入できます。
- **保存**すると、仕訳を `journals/YYYY-MM/` に書き込みます。日付を変えると、
  その月のフォルダに移ります。
- 保存のたびに、**保存済みの内容のチェック**が `iris validate` と同じチェックを
  実行します。この仕訳の問題を一覧にし、帳簿の他の箇所のエラーの件数も示します。

帳簿のレポートを止めてしまう仕訳は保存できません：金額が空欄、勘定科目のない
明細、借方と貸方の両方がある明細、帳簿の会計年度外の日付です。記帳は別の操作
なので、ステータスの変更も保存できません。勘定科目表にない科目を使った仕訳と、
貸借が合わない下書きは保存され、チェックで指摘されます。貸借が合うまで
**記帳**は選べません。

チェックで帳簿独自のオーバーレイ層がこのパソコンで信頼されていないと表示された
ときは、内容を確認して `iris overlay trust` を実行します。

記帳済の仕訳は、記帳済のまま内容が変わります。記帳できない内容への変更は保存
できないので、記帳済の仕訳は常に貸借が合っています。クラウドにリンクした帳簿
では、変更前の内容が次の同期のあとクラウドの仕訳の履歴に残ります。同期しない
帳簿には、変更前の内容は残りません。年度が締め済みのとき、または**記帳承認**が
オンのときは、サーバーが変更を拒否するため、記帳済の仕訳はここでは編集できません。
元の仕訳をそのまま残し、修正を新しい仕訳として記録するには、
**この仕訳を訂正**を使います。

## 新しい仕訳と訂正

**仕訳帳**の**新しい仕訳**を選ぶと、今日の日付の下書きを作り始めます。前の年度の
帳簿では、その年度の中の日付で始まります。ファイル名は日付と取引先から付きます。

記帳済の仕訳で**この仕訳を訂正**を選ぶと、元の仕訳を取り消す明細を入れた新しい
下書きを作ります。添付の参照も引き継ぎます。その下に正しい明細を追加して保存し、
訂正の仕訳を記帳します。元の記帳済の仕訳はそのまま残ります。

## プラグイン

**プラグイン**には、この帳簿にコピーがあるプラグイン（`iris` では
[オーバーレイ](concepts.md#地域のルール-オーバーレイ) と呼びます）が、共通と地域別に分かれて
並びます。その下にあるのが、常に実行される**基本チェック**です。ほかのプラグインを
必要とするプラグインは、そのプラグインの下に表示されます。プラグインを選ぶと、
帳簿に追加されるチェック・計算・値の提案・補完・項目・タスク・ガイドと、
プラグイン自身の説明を確認できます。

プラグインをオン・オフするには、スイッチか**オンにする**・**オフにする**を
使います。先に変更内容が表示されます。あわせてオン・オフになるプラグイン
（ほかのプラグインが必要としているプラグインだけをオフにすることはできません）、
開始・停止するもの、これらのプラグインで記録した結果の件数です。確定するまで
何も書き込まず、確定すると確認した内容のとおりに書き込みます。途中で帳簿が
変わった場合は、もう一度確認するよう求められます。変更されるのは
`config/book.yaml` の `overlays:` で、
[`iris overlay select`](cli-reference.md#iris-overlay) と同じです。オフにした
プラグインのコピーは帳簿に残り、そのプラグインで記録した数値は引き続き検証
されます。クラウドと連携した帳簿では、次の同期でクラウドに反映されます。

**設定**のあるプラグインでは、プラグインが宣言する帳簿全体の項目（方式の選択など）
がフォームで表示されます。項目は適用されるときだけ表示されるため、ある値を選ぶと、
それに必要な別の項目が現れることがあります。勘定科目や単位を指す設定では、勘定科目表や
定義済みの単位から選べます。帳簿にないものが指定されていれば、その旨を表示します。
項目ごとの説明がないプラグインの設定は YAML で記入します。保存の前に `config/book.yaml` の変更内容が表示され、そのとおりに
保存します。コメントやほかの設定はそのまま残ります。途中で帳簿が変わった場合は、
もう一度確認するよう求められます。

帳簿の年度が締め済みのとき、または帳簿がアーカイブのときは、ここでは何も変更できません。

**追加できるプラグイン**には、お使いの `iris` に同梱されていて、帳簿にまだない
プラグインが並びます。ダウンロードはしません。**追加**を選ぶと同じように変更内容が
表示され、各プラグイン自身のテストの結果も確認できます。確定すると、その版のまま
プラグインを帳簿にコピーしてオンにします。必要なプラグインがあれば一緒に追加します。
ほかの地域の帳簿向けのプラグインは**ほかの地域**に表示され、追加できません。
お使いの `iris` より後に公開されたプラグインは表示されません。AI アシスタントに頼むか、
版を指定して `iris overlay install --pin` を実行してください。帳簿にすでにある
プラグインの新しい版への切り替えはアップグレードです。`iris overlay upgrade` を
使ってください。

`config/overlays/` にある帳簿独自の定義は一番上に表示されます。
`iris overlay trust` で信頼するまで実行されません。

[デモ](https://irisbooks.io/demo/)では、プラグインのオン・オフ、追加、設定の変更で
何が変わるかを、実際には変更せずに確認できます。

## 価格と通貨

**純資産**は、このパソコンに記録した価格と、フォルダ独自の価格があればそれを
使って保有資産を評価します。価格の一覧は**設定**にあります。価格や為替レートを
記録するには、AI アシスタントに頼むか
[`iris price add`](cli-reference.md#iris-price) を実行します。`--books-dir`
を付けると、そのフォルダの価格として記録します。

帳簿ごとに通貨が違うフォルダでは、ダッシュボードと純資産に表示通貨が必要です。
フォルダの `.irisbooks/settings.yaml` か、あなた自身の
`~/.config/irisbooks/settings.yaml` に `reporting_currency` を設定するか、
`--currency` を付けます（例：
`iris view --books-dir ~/IrisBooks --currency JPY`）。設定がなくても各帳簿は
開けます。Web アプリと同じく、ダッシュボードの換算レートの欄で変えた値は
その表示だけに使われ、保存されません。

## 複数のウィンドウ

ウィンドウはいくつでも開けます。別のフォルダでも、同じフォルダでもかまいません。
どのウィンドウも、アドレスに入っている帳簿を表示します。

2つのウィンドウで同じ仕訳を変更すると、後から保存したほうは「開いた後でこの仕訳が
変更されました。もう一度確認してください。」と表示されて保存されず、入力した
内容は欄に残ります。必要な内容を控えてから**仕訳を読み直す**を選ぶと、もう一方の
ウィンドウの変更が表示されます。

## プライバシーと終了

- 画面は、このパソコンの `127.0.0.1` で `iris` が表示します。読むのは帳簿の
  ファイルだけで、アカウントは不要、どこにも何も送りません。
- `iris view` は1回限りのリンクでブラウザにサインインします。このリンクは
  画面に表示しません。
- 専用ウィンドウは拡張機能をオフにした専用のブラウザプロファイルを使うので、
  ブラウザの拡張機能がこの画面を通して帳簿を読むことはできません。いつもの
  ブラウザのタブで開いた場合は、この保護はありません。

最後のウィンドウを閉じてからおよそ5分で、画面は自動的に終了します。すぐに
終了するには `iris view --stop` を、動いているかどうかを確かめるには
`iris view --status` を実行します。終了後に開いたままの画面には「この画面は
閉じられました。もう一度IrisBooksを開いてください。」と表示されます。

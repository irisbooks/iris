# はじめに

事業主も税理士も、帳簿ファイルと自分の AI で作業するところから始めます。
ローカルの **`iris` CLI** はアカウントもネット接続も不要です。必要に応じて
**Web アプリ**で閲覧・レビュー・クラウドの管理も行います。このページでは両方を案内します。

税理士は顧客ごとに AI の作業フォルダとセッションを分け、共有された既存の
帳簿を clone します。新しい識別子で別帳簿を作る必要はありません。フォルダと
ツールのアクセス範囲は [ファイルでの進め方](cli-and-llm.md) を参照してください。

## 経路 A — 自分のマシンで帳簿を作る（CLI）

### 1. `iris` をインストールする

CLI は無料で、**現状のまま（as is）**提供します。個別サポート、不具合の修正、
継続的な更新は保証しません。詳しくは [CLI の利用とサポート](cli-and-llm.md#cli-の利用とサポート) を参照してください。

`iris` は単一のバイナリです。macOS / Linux では:

```bash
curl -fsSL https://irisbooks.io/install.sh | sh
```

Windows（PowerShell）では:

```powershell
irm https://irisbooks.io/install.ps1 | iex
```

インストーラーがお使いのプラットフォーム向けバイナリをダウンロードし、
署名を検証して `PATH` に配置します。次のコマンドで確認します。

```bash
iris version
```

`iris` が見つからない場合は、新しいターミナルを開くか（`PATH` の変更は
新しいシェルから有効になります）、上のインストールコマンドをもう一度
実行してください。

### 2. 最初の帳簿を作る

空のディレクトリでガイド付きウィザードを実行します。

```bash
iris init
```

ウィザードは、帳簿名、地域（region）、言語、会計年度の開始月（既定は1月）、
この帳簿が扱う会計年度を順に尋ねます（帳簿は1年に1冊です。
前年度の申告をこれから済ませるなら前年度を選びます）。最後に、検証を通った仕訳を AI アシスタントに
**自動で記帳**させるかを聞きます（「いいえ」なら、自分で確認してから記帳します。
あとで `AGENTS.md` の「記帳ポリシー」を編集すれば変えられます）。答え終わると
フォルダが生成されます。質問を飛ばして一括指定もできます。

```bash
iris init --name "Acme Design" --region JP --language ja \
  --fiscal-start-month 4 .
```

`--sample` を付けると、試せるデモ仕訳が約40件入ります（あとで削除可能）。
全フラグは [`iris init`](cli-reference.md) を参照してください。

### 3. 帳簿を自分用に整える

`config/chart-of-accounts.yaml` を開き、勘定科目を自分の事業に合わせます。
次に**期首残高**（現金・預金・売掛金・買掛金・借入金など）を最初の仕訳として、
帳簿の会計年度の初日付で `opening-balance` タグを付けて記帳します（`iris yearend`
が翌年度の帳簿に書く期首残高仕訳にも同じタグが自動で付きます。繰り越した残高は
入金ではないので、資産増減のレポートからは除かれます）。
他システムから移行する場合は、移行日時点の旧システムの試算表と一致させて
ください。（`notes/todos.md` にこのタスクのリマインダーがあります。）

### 4. AI アシスタントをつなぐ

AI が CLI を実行でき、このフォルダを読み書きできるなら追加の接続設定は不要です。
`AGENTS.md` を読んで作業を始められます。MCP クライアントの接続や不足する案内の追加には、
次を実行します。

```bash
iris onboard
```

これにより `iris mcp serve` が MCP 対応クライアント（Claude Code・Claude
Desktop・Codex・Cursor・Gemini CLI・VS Code）に登録され、アシスタントが
帳簿内での作業手順を理解するための Claude Code スキルが書き込まれます。詳しい
流れは [CLI と自分の LLM で記帳する](cli-and-llm.md) を参照。AI は作業前に
帳簿ルートの `AGENTS.md` を読みます。

### 5. 毎日のループ

```bash
# 1. 資料を渡す、AI が読める場所を伝える、または家計の現金残高を話す
# 2. AI が元資料を raw/ に保存し、仕訳の下書き（status: draft）を作る
# 3. 構造と計算をチェック
iris validate
# 4. 現状を確認
iris balance
iris report pl --from 2026-04-01 --to 2026-06-30
```

資料の保存は AI に任せられます。自分で `raw/` に移す必要はありません。
家計の支出なら、残高と短い聞き取りから始め、推定は明記します。事業の記録は
正確さと根拠となる資料を大切にします。詳しくは [毎日の進め方](cli-and-llm.md) を
参照してください。ローカルの `iris` はアカウントもネット接続も不要ですが、
AI サービスには接続が必要な場合があります。

## 経路 B — Web アプリを使う（クラウド）

Web アプリは、GUI・クラウド同期・複数端末アクセス・共同作業・改ざんの見える
履歴を提供します。IrisBooks アカウントが必要です。

### 1. サインインする

クラウドは招待制です。[Discordコミュニティ](https://discord.gg/wZDsv9gyb9)で
招待を依頼し、招待されたメールアドレスで[Webアプリ](https://irisbooks.io/app/)に
サインインします。税理士が帳簿を共有している場合は、その帳簿が表示されます。

### 2. 帳簿を作る

ローカル帳簿がすでにある場合は、ウィザードの **パソコンに IrisBooks の帳簿がある場合** を
選び、次のリンク手順を先に行ってください。リンクと同期が済んだら **帳簿一覧を更新** を
押すと、その帳簿を開けます。

まだ帳簿が1つもなければ、アプリは **新規帳簿**ウィザードを表示します。帳簿名と
地域を入力し、対象の会計年度と会計年度の開始月を選ぶと、クラウド上に帳簿が
作られます（開始月の初期値は1月です）。作成時点で
`config/book.yaml`、ひな形の勘定科目表、`AGENTS.md` が入っているため、`iris clone <book-id>`
だけで、すぐ使えるローカルフォルダが手に入ります。

地域と会計年度の開始月は、最初の仕訳を記帳した後は変更できません。
確認画面に最初の会計年度の期間が出るので、そこで確かめてください。

### 3. 既存のローカル帳簿をリンクする（任意）

経路 A でディスク上に帳簿がある場合、両者を接続して同期できます。

```bash
IRISBOOKS_APP_BASE=https://irisbooks.io IRISBOOKS_API_BASE=https://irisbooks.io/api iris api login
iris api books new             # または: iris api books link <book-id>
iris sync                      # ローカルファイルを push
```

PowerShellでは、`iris api login`の前に
`$env:IRISBOOKS_APP_BASE = 'https://irisbooks.io'`と
`$env:IRISBOOKS_API_BASE = 'https://irisbooks.io/api'`を設定します。
ログインに成功すると接続先が保存されます。地域別のサービスでは、
アカウントとクラウド帳簿をそれぞれ管理します。

帳簿のフォルダの中で実行すると、`iris api books new` はそのフォルダの設定
（帳簿名・会計年度・地域など）のままクラウド帳簿を作り、フォルダに自動で link
します。次の行の `iris sync` がそのまま動くのはこのためです。すでに Web アプリで帳簿を作成済みの場合は、アプリに表示された ID を使って
`iris api books link` を実行してください。ここで `new` を実行すると、帳簿がもう1つ
できてしまいます。

これで同じ帳簿に CLI と Web アプリの両方からアクセスできます。同期が何を
変え、何を変えないかは
[基本コンセプト → 同期](concepts.md) を参照してください。

### 4. アプリで作業する

上部バーには**ダッシュボード**タブと帳簿プレートがあり、そこで帳簿を選んで
中に入ります。帳簿の中では、左サイドバーにその帳簿の画面 — 仕訳、
アクティビティ、各レポート、管理グループ（勘定科目、元資料、ノート、
年度の締め、設定）— が並びます。右上のアバターからあなたの設定を
開けます。詳しくは [Web アプリを使う](web-app.md)。

## アカウントは必要か

記帳そのものには不要です — ローカルファイルと CLI だけで完結します。
IrisBooks アカウントは、同期・Web アプリ・共同作業、そしてサーバー側に残る
訂正・削除の恒久履歴を追加します。
[基本コンセプト → 同期](concepts.md) を参照してください。

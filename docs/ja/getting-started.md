# はじめに

家計でも事業でも、帳簿のファイルと自分の AI で作業するところから始めます。
パソコンで動かす **`iris` CLI** は、アカウントもネット接続も不要です。クラウドを
使う場合は、**Web アプリ**で閲覧・レビュー・クラウドの管理もできます。このページでは
両方の始め方を案内します。

税理士の方は、顧客から共有された帳簿を自分のパソコンに複製して（`iris clone`）
作業します。顧客ごとに帳簿を作り直す必要はありません。AI の作業フォルダと
セッションは顧客ごとに分けてください。詳しくは
[税理士も顧客ごとの作業フォルダで記帳する](cli-and-llm.md#税理士も顧客ごとの作業フォルダで記帳する)を
参照してください。

## サンプルの帳簿で試す

自分の帳簿を作る前に、[デモ](https://irisbooks.io/demo/)でサンプルの帳簿を
見て回れます。デモには、架空の商店と、その事業主の家計の帳簿が入っています。
画面は `iris view` がパソコンで表示するものと同じで、`iris` そのものがブラウザの
中で動きます。日本語と英語で使え、アカウントは要りません。下書きを直して記帳し、
レポートが変わるのを確かめられます。データはブラウザの外に出ません。変更は、
ページを再読み込みすると元に戻ります。帳簿の日付は、今年度の記録が今日まで
続くように調整してあります。

同じ帳簿を自分の AI で試すには、デモの**手元で試す**から zip をダウンロードします。
zip にはデモで加えた変更も入ります。`iris` のインストール方法と、帳簿を Claude Code や
Codex で開く手順は、zip の中の README にあります。`iris` をインストール済みなら、
`iris view --books-dir <展開したフォルダ>` で、デモと同じ画面をパソコンで開けます。
このときも何もアップロードしません。なお、パソコンで開いた場合の純資産の額は
デモと異なります。家計の投資信託とコインが、`iris price add` で価格を記録するまで
取得原価で評価されるためです。

## アカウントは必要か

記帳そのものには不要です。パソコンのファイルと CLI だけで完結し、`iris view` で
画面から見ることもできます。IrisBooks のアカウントを作ると、クラウドとの同期、
Web アプリ、共同作業、サーバーに残る訂正・削除の履歴が加わります
（[基本コンセプト → 同期](concepts.md#同期-3つの働き方)）。

アカウントなしで始めるなら経路 A だけで足ります。クラウドも使うなら、経路 A で
帳簿を作ってから経路 B に進むのが基本です。

## 経路 A — 自分のパソコンで帳簿を作る（CLI）

### 1. `iris` の有無を確認する

`iris --version` を実行します。バージョンが表示されれば `iris` はインストール済みです。
そのまま使い、最新版にしたいときは `iris update` を実行します。表示されない場合は、
次の手順でインストールします。

CLI は無料で、**現状のまま（as is）**提供します。個別サポート、不具合の修正、
継続的な更新は保証しません。詳しくは [CLI の利用とサポート](cli-and-llm.md#cli-の利用とサポート) を参照してください。

`iris` は1つの実行ファイルです。macOS / Linux では次のコマンドでインストールします。

```bash
curl -fsSL https://irisbooks.io/install.sh | sh
```

Windows（PowerShell）では次のコマンドです。

```powershell
irm https://irisbooks.io/install.ps1 | iex
```

インストーラーは、お使いの環境向けの実行ファイルをダウンロードし、公開された
ものと一致することを確かめてから `PATH` に配置します。一致しなければインストール
しません。デスクトップでの初回インストールでは、ターミナルなしで帳簿を開けるよう
**IrisBooks** もアプリに追加します（[ランチャー](iris-view.md#ランチャー)を参照）。
追加しない場合は `IRIS_NO_LAUNCHER=1` を指定します。更新のときは追加しません。
インストールしたバージョンは次のコマンドで確認します。

```bash
iris --version
```

`iris` がまだ見つからない場合は、新しいターミナルを開くか、インストーラーが
表示した実行ファイルの絶対パスを使います。もう1つ別にインストールする前に、
`PATH` を確認してください。

> **検証のしくみ**　インストーラーは、現行リリースの SHA-256 チェックサムを
> 自分の中に持っています。このチェックサムは署名済みのリリースから取り込まれ、
> ダウンロード元とは別の irisbooks.io から配信されます。そのため、`minisign` が
> なくても、改ざんされたダウンロードは拒否されます。`IRIS_VERSION` で別の
> バージョンを入れる場合は、先に `minisign` をインストールしてください。
> インストーラーはそのリリースの署名済みチェックサムファイルを検証し、`minisign` が
> なければ中止します。インストール後の `iris update` は検証機能を内蔵しているので、
> `minisign` は要りません。

### 2. 最初の帳簿を作る

空のフォルダで、質問に答えていく形式のウィザードを実行します。

```bash
iris init
```

ウィザードは次の項目を順に尋ね、答え終わると帳簿のフォルダを作ります。

| 質問 | 既定値と補足 |
| --- | --- |
| 帳簿名 | — |
| 地域（region） | 必須。既定値はありません |
| 通貨 | 地域の通貨 |
| 会計年度の開始月 | 1月 |
| この帳簿が扱う会計年度 | 帳簿は1年に1冊です。前年度の申告をこれから済ませるなら、前年度を選びます |
| 検証を通った仕訳を AI に**自動で記帳**させるか | 「いいえ」なら、自分で確認してから記帳します。あとで `AGENTS.md` の「記帳ポリシー」を編集すれば変えられます |

質問を飛ばして、フラグでまとめて指定することもできます。

```bash
iris init --name "Acme Design" --region JP --language ja \
  --fiscal-start-month 4 .
```

`--sample` を付けると、試しに触れるデモの仕訳が約40件入ります。あとで削除できます。
すべてのフラグは [`iris init`](cli-reference.md) を参照してください。

ターミナルを使わずに作ることもできます。アプリ一覧から **IrisBooks** を開き、
**帳簿を作成**を選んでください。同じ質問に、1つのフォームでまとめて答えられます。
詳しくは [帳簿を作成する](iris-view.md#帳簿を作成する)を参照してください。

### 3. 帳簿を自分用に整える

まず `config/chart-of-accounts.yaml` を開き、勘定科目を自分の事業や家計に
合わせます。

次に、**期首残高**（年度の初めに持っている現金・預金・売掛金・買掛金・借入金など）を
最初の仕訳として記帳します。日付は帳簿の会計年度の初日にし、`opening-balance` タグを
付けます。このタグを付けた仕訳は、資産の増減のレポートから除かれます。繰り越した
残高は入金ではないためです。`iris yearend` が翌年度の帳簿に書く期首残高の仕訳にも、
同じタグが自動で付きます。ほかのシステムから移行する場合は、移行日時点の旧システムの
試算表と金額を一致させてください。この作業は `notes/todos.md` にも載っています。

投資信託・株式・暗号資産のように数量で数える資産を、前の年度までに取得して
持っている場合は、追加で2つの作業があります。

1. 期首残高の仕訳に、その資産の数量と単位を付けます。
2. `config/book.yaml` の `opening_inventory` に、まだ残っている購入分を
   ロット（元の取得日・数量・原価）として書きます。

こうすると、帳簿は取得原価を簿価とは別に保持します。その後の売却では、既定で
古いロットから順に使われ、`iris yearend` は残ったロットを翌年度の帳簿に引き継ぎます。
過年度の購入そのものは、この帳簿の会計年度の外なので仕訳にはできません。詳しくは
[取得原価の期首情報](book-format-reference.md#独立した年度帳簿と取得原価の期首情報)を
参照してください。

### 4. AI アシスタントをつなぐ

AI がコマンドを実行でき、このフォルダを読み書きできるなら、追加の接続設定は
要りません。AI は帳簿のフォルダ直下にある `AGENTS.md`（作業ガイド）を読んでから
作業を始めます。Claude または ChatGPT のデスクトップアプリを使っているなら、
`iris view` で帳簿の**概要**を開くと、帳簿のフォルダでセッションを始められます。
詳しくは [AI と一緒に帳簿をつける](iris-view.md#ai-と一緒に帳簿をつける)を参照してください。

AI アプリが `iris` を道具として直接呼び出せるようにする接続方式を MCP と呼びます。
MCP で接続したい場合や、帳簿に足りない案内ファイルを追加したい場合は、次を実行します。

```bash
iris onboard
```

このコマンドは、MCP に対応した AI アプリ（Claude Code・Claude Desktop・Codex・
Cursor・Gemini CLI・VS Code）に `iris` の MCP サーバー（`iris mcp serve`）を登録します。
あわせて、帳簿での作業手順を AI に伝える Claude Code スキルを書き込みます。詳しくは
[最初の一度: AI をつなぐ](cli-and-llm.md#最初の一度-ai-をつなぐ)を参照してください。

### 5. 毎日のループ

```bash
# 1. 資料を渡す、AI が読める場所を伝える、または家計の現金残高を話す
# 2. AI が元資料を raw/ に保存し、仕訳の下書き（status: draft）を作る
# 3. 構造と計算をチェック
iris validate
# 4. 現状を確認
iris balance
iris report pl --from 2026-04-01 --to 2026-06-30
```

資料の保存は AI に任せられます。自分で `raw/` に移す必要はありません。
家計の支出なら、残高と短い聞き取りから始められます。その場合、推定した金額は
推定と明記します。事業の記録では、金額の正確さと根拠になる資料が必要です。
`iris` 自体はアカウントもネット接続も要りませんが、AI サービスには接続が必要な
場合があります。

各手順の詳しい進め方は[毎日のループ](cli-and-llm.md#毎日のループ)に、保存した資料・
下書き・記帳済の仕訳がそれぞれ何に使えるかは
[全体イメージ](cli-and-llm.md#全体イメージ)にあります。

### 6. 画面で帳簿を見る

```bash
iris view
```

帳簿を専用のウィンドウで開き、レポート・仕訳・資料をファイルから読み込んで
表示します。AI が用意した下書きを記帳する、下書きを直す、自分で仕訳を作る、
といった操作もここでできます。アカウントは要りません。ターミナルを使わずに
開きたい場合は、アプリから **IrisBooks** を開き、帳簿のフォルダを選びます。
見つからなければ、`iris view --add-launcher` で追加します。詳しくは
[このパソコンで帳簿を開く](iris-view.md)を参照してください。

## 経路 B — Web アプリを使う（クラウド）

Web アプリを使うと、ブラウザの画面で帳簿を見られるほか、クラウドとの同期、
複数の端末からのアクセス、共同作業、サーバーに残る訂正・削除の履歴が使えます。
IrisBooks のアカウントが必要です。

### 1. サインインする

クラウドは招待制です。[Discordコミュニティ](https://discord.gg/wZDsv9gyb9)で
招待を依頼し、招待されたメールアドレスで[Webアプリ](https://irisbooks.io/app/)に
サインインします。税理士から帳簿に招待されている場合は、ダッシュボードで招待を
承認すると帳簿を開けます。

### 2. 帳簿を作る

帳簿がまだ1冊もないと、アプリは**新規帳簿**ウィザードを表示します。次の項目を
入力すると、クラウドに帳簿が作られます。

- 帳簿名
- 地域。既定値はありません。選ぶとその地域の通貨が入り、通貨は変更できます。
- 帳簿が扱う会計年度
- 会計年度の開始月。初期値は1月です。

作られた帳簿には、最初から `config/book.yaml`、ひな形の勘定科目表、`AGENTS.md` が
入っています。そのため、`iris clone <book-id>` を実行するだけで、すぐに使える
フォルダがパソコンにできます。

地域と会計年度の開始月は、最初の仕訳を記帳した後は変更できません。確認画面に
最初の会計年度の期間が表示されるので、そこで確かめてください。

経路 A などで、すでにパソコンに帳簿がある場合は、ここで新しい帳簿を作りません。
ウィザードの**パソコンに IrisBooks の帳簿がある場合**を選び、次の手順 3 で
その帳簿をクラウドにリンクします。リンクと同期が済んだら**帳簿一覧を更新**を
押すと、その帳簿を開けます。

### 3. 既存のローカル帳簿をリンクする（任意）

経路 A で作った帳簿がパソコンにある場合は、クラウドの帳簿と結び付けて
（リンクして）同期できます。帳簿のフォルダの中で、次のコマンドを実行します。

```bash
iris api login                 # サインイン
iris api books new             # クラウドに帳簿を作り、このフォルダとリンクする
iris sync                      # パソコンのファイルをクラウドへ送る
```

`iris api books new` は、フォルダの設定（帳簿名・会計年度・地域など）をそのまま
使ってクラウドに帳簿を作り、フォルダと自動でリンクします。続けて `iris sync` を
実行できるのはこのためです。

すでに Web アプリで帳簿を作ってある場合は、`new` の代わりに、アプリに表示された
ID を指定して `iris api books link <book-id>` を実行します。ここで `new` を
実行すると、帳簿がもう1つできてしまいます。

`iris api login` はブラウザで認証するので、CLI を実行するパソコンにブラウザが
必要です。サーバーや AI の VM のようにブラウザがない環境では、`iris api login --device` を
実行し、自分のスマートフォンで承認してから `iris api login --device-complete` を
実行します。どちらの場合も、帳簿の作成・リンク・同期の前に `iris api whoami` で、
サインインしたアカウントを確かめてください。詳しくは
[ログイン方式とアカウントの分離](cli-reference.md#iris-api-login)を参照してください。

これで、同じ帳簿を CLI と Web アプリの両方から使えます。同期で何が変わり、何が
変わらないかは [基本コンセプト → 同期](concepts.md#同期-3つの働き方) を参照してください。

### 4. アプリで作業する

左のサイドバーの**帳簿一覧**で帳簿を選ぶと、その帳簿の画面（概要、仕訳帳、
アクティビティ、各レポート、ファイル、勘定科目、ノート、年度の締め、帳簿の設定）が
並びます。複数の帳簿をまとめた集計は**ダッシュボード**と**純資産**で見られます。
右上の歯車アイコンから、あなた自身の設定を開けます。詳しくは
[Web アプリを使う](web-app.md#レイアウト)を参照してください。

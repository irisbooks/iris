# 外出先の AI から帳簿へ（リモートコネクタ）

リモートコネクタは、パソコンから離れているときに、AI アプリから帳簿を読むための
機能です。読むのはクラウドに同期済みのコピーで、スマートフォンやブラウザの AI に
数字を尋ねたり、仕訳や帳簿に保存した参考情報を確認したりできます。

記帳については**読み取り専用**です。記録を作成・変更するには、帳簿の会計ルールで
検証する必要があり、その検証はあなたのパソコンでしか実行されないためです。変更は
ローカルの CLI かローカルの MCP で行い、同期すると、リモートコネクタからも
見えるようになります。例外は1つだけで、領収書の写真などの元資料のアップロードを
任意で許可できます。アップロードはファイルを保存するだけで、記録には触れません。

接続には MCP を使います。対応する AI アプリは **Claude**（モバイル・Web・
デスクトップ・Claude Code）と **ChatGPT** です。対応アプリは Client ID Metadata
Document で識別するため、現在、ほかの MCP アプリはサインインを完了できません。

帳簿を選ぶと、AI はまず `read_book_guide` で、同期済みの `AGENTS.md`（帳簿ごとの
作業ガイド）を読みます。ガイドに何が書いてあっても、コネクタの権限が読み取り専用から
広がることはありません。

## セットアップ

1. AI アプリに次の URL でカスタムコネクタを追加します。

   ```text
   https://irisbooks.io/mcp
   ```

   Claude では「設定 → コネクタ → カスタムコネクタを追加」です。
2. ブラウザでサインインし、**閲覧者 — 読み取り専用**のアクセスを許可します。
   元資料をアップロードしたい場合は、**証憑ファイルのアップロード**も許可します。
   下書きを作成する権限は選べません。AI アプリがブラウザと同じパソコンで動いている
   場合は、localhost についての注意書きが表示されます。自分で接続を始めた直後で
   あることを確かめてから許可してください。
3. AI に帳簿の一覧を取得してもらい、対象の帳簿を選びます。コネクタが読めるのは、
   あなたがいまアクセス権を持っている帳簿だけです。

コネクタの権限は次のとおりです。

- 新しい接続は閲覧者の権限になります。アップロードも許可した場合は
  `evidence:upload` 権限が加わり、元資料のアップロード用リンクを発行できます。
- 以前に記帳担当として許可した接続も、現在は閲覧と元資料のアップロードに
  限定されます。
- 接続を更新しても、許可した権限の組み合わせは変わりません。
- 一般の REST API では、コネクタのトークンは閲覧者の権限だけを持ちます。

ローカルの CLI のサインインと、帳簿でのあなたの役割は、コネクタとは別に管理されます。
コネクタの設定を変えても影響しません。

## どこからでもできること

- **レポートを読む** — `get_report` で試算表、損益計算書、貸借対照表、科目元帳、
  グループ別集計を取得します。通常の帳簿では、記帳済の仕訳から計算します。
  会計ビューのある帳簿では、現在の入力に対して承認済みの計算結果を使います。取得できる場合は同期時点 `figures_as_of` も返します。
- **キャッシュ・フロー計算書を読む** — `get_report(report="cash-flow-statement")`
  で、勘定科目表で現金とした科目の動きを営業・投資・財務の活動ごとに、期首と期末の
  現金とともに取得します。
- **資産の増減を確認する** — `get_report(report="cashflow")` は従来の名前です。
  売掛金や固定資産も含む全資産の月別の増減を集計し、振替は両側に計上されます。
  キャッシュ・フロー計算書ではありません。
- **仕訳と科目を読む** — `list_accounts`、`search_journals`、`get_journal` を使います。
  検索条件は AND で組み合わせます。金額は下限・上限も含め、仕訳ファイルと同じ
  帳簿通貨の10進数の文字列（`"98.00"`）です。
  同じ条件で `nextCursor` を渡して続きを読みます。検索結果の `journal_path` で仕訳を指定し、
  締め済み年度の仕訳は `closed` と表示します。
- **純資産・保有数量・価格を読む** — `get_networth`、`get_holdings`、`list_prices` は
  同期済みのクラウドデータを読みます。価格一覧は `unit`・`currency`・`year`・`limit`・
  `cursor` を指定でき、`nextCursor` が空になるまで続きを取得します。
  価格は帳簿ではなく、サインインしているユーザーごとに記録されたものです。`as_of` を
  省略した場合、純資産では集計時の基準日を、保有数量では今日の日付を使います。
- **パッケージの参考情報を読む** — `get_book_context` は保存済みの選択、タスク・項目の
  定義、設定、ガイドの節、宣言済みの例を返します。権限と帳簿の版を確認しますが、
  CEL の実行、記録の検証、レシピ計算は行いません。
- **年度の状態を確認する** — `fiscal_years` で open・closed・reopened、仕訳件数、
  締めを妨げる下書きの件数を確認します。
- **元資料をアップロードする** — アップロードの許可と帳簿のオーナー権限か記帳担当権限があれば、
  `create_upload_link(book_id=...)` で画像・PDF 用の一度限りのリンクを発行できます
  （15分、10 MB まで）。アップロードされたファイルは、ウイルススキャンのあと
  `raw/uploads/` に保存されます。このツールは `journal_path` を受け付けず、仕訳の編集も
  添付の変更もしません。アップロード画面にファイルが届いたと表示されるのを待って
  ください。仕訳への関連付けは、あとでローカルで行います。
- **既存の受信アドレスを調べる** — `get_inbox_address` は既存の情報を読むだけで、
  メール送信やアップロードリンクの作成は行いません。

クラウドの帳簿は、`list_books` が返す `book_id` で指定します。`get_report` の
引数は、レポートの種類によって決まります。

| レポート | 引数 |
| --- | --- |
| 試算表 | `as_of`。`from` も付けると期間の試算表 |
| 貸借対照表 | `as_of`。前期と比較するときは `compare: prior-year` |
| 損益計算書 | `from`・`to`。前期と比較するときは `compare: prior-year` |
| 月次推移表（`trend`） | `from`・`to` |
| キャッシュ・フロー計算書（`cash-flow-statement`） | `from`・`to` |
| 元帳 | `account` と、`from`・`to` または `as_of` |
| グループ別集計 | `by` と、`from`・`to` または `year` |
| 資産の増減（`cashflow`） | `year` |

そのレポートで使わない引数、型の誤り、不明な引数、開始日と終了日の逆転は、
無視されずエラーになります。

純資産は、Web の帳簿横断レポートと同じ集計結果を使います。集計は**ユーザーごとに
1日1回（UTC）**自動で行われます。日付・帳簿の選択・通貨を変えても、集計に取り込んだ
データは更新されません。`snapshot.generatedAt` が集計した時刻、
`snapshot.nextRefreshAt` が次に自動で集計する時刻です。同期した変更をそれより早く
反映したいときは、Web のダッシュボードか純資産の画面で**集計を実行**を選びます。
リモートコネクタは更新後の集計を読めますが、この操作そのものは実行できません。

## あえてできないこと

リモートコネクタからは、次の操作はできません。

- 仕訳の作成・編集・削除
- 価格の記録
- 補完の適用、レシピの計算
- 記帳・承認
- 年度の締め・再オープン

以前の版にあった下書きの作成機能は、現在はありません。元資料のアップロードは、
許可した場合にだけ使えます。アップロードしても、会計記録は作成も変更もされません。
記帳に関わる変更は、ローカルの CLI かローカルの MCP で行ってください。帳簿で選んだ
会計ルールと検証を通してから同期するためです。

## コンピュータの前か、外出先か

| 状況 | 使うもの | 利用できること |
| --- | --- | --- |
| コンピュータの前 | [ローカルの設定](cli-and-llm.md) | 手元のファイルで作成 → 検証 → 記帳 → 同期 |
| 外出先 | リモートコネクタ | クラウドのレポート・仕訳・参考情報の閲覧と、許可した場合は元資料のアップロード |

両方を設定してかまいません。両方を使える AI は、ローカルを優先するよう案内されます。
ローカルなら、まだ同期していない編集も読めるためです。帳簿のあるコンピュータで AI が
`iris` を実行でき、サインイン済みであれば、CLI からクラウドの帳簿も読めるため、
コネクタは必要ありません。

## 接続の解除

AI アプリでコネクタを削除するか、IrisBooks の「あなたの設定 → 接続中のアプリ」で
**接続解除**を選びます。解除すると、次のリクエストから拒否されます。解除の時点で
すでに受け付けていた処理は、最後まで実行されることがあります。接続を解除しても、
帳簿でのあなたの役割は変わりません。役割は帳簿の「設定 → 権限」で管理します。

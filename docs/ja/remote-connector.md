# 外出先の AI から帳簿へ（リモートコネクタ）

リモートコネクタは、同期済みの帳簿のクラウドコピーを AI アプリから読むための機能です。
スマートフォンやブラウザから、集計値、仕訳、保存済みの参考情報を確認できます。

初回リリースの記帳機能は**読み取り専用**です。例外として、会計ルールを実行しない
元資料のアップロードを任意で許可できます。記録の作成・変更には、帳簿の会計ルールを
ローカルで実行する必要があります。変更はローカル CLI またはローカル MCP で行い、
同期してからリモートで確認してください。

MCP に対応し、**Claude**（モバイル・Web・デスクトップ・Claude Code）と
**ChatGPT** を利用できます。対応アプリの識別には Client ID Metadata Document を使います。
現在、ほかの MCP アプリはサインインを完了できません。

帳簿を選んだら、AI は `read_book_guide` で同期済みの `AGENTS.md` を読みます。
帳簿の方針によって、コネクタの読み取り専用の権限が広がることはありません。

## セットアップ

1. AI アプリに次の URL でカスタムコネクタを追加します。

   ```text
   https://irisbooks.io/mcp
   ```

   Claude では「設定 → コネクタ → カスタムコネクタを追加」です。
2. ブラウザでサインインし、**閲覧者 — 読み取り専用**のアクセスを許可します。
   必要な場合は**証憑ファイルのアップロード**も許可します。下書き作成の権限はありません。アプリがこのコンピュータで動く場合は、
   自分で接続を開始した直後に限り、localhost の注意書きを確認して許可してください。
3. AI に帳簿の一覧を取得させ、対象を選びます。現在の帳簿へのアクセス権も適用され、
   権限のない帳簿は読めません。

以前の記帳担当の接続も、閲覧と元資料のアップロードに限定します。新規接続は閲覧者が既定で、
任意の `evidence:upload` 権限を追加すると元資料用のリンクを発行できます。更新時も許可済みの
組み合わせを保ちます。一般の REST API に対しては、コネクタのトークンは閲覧者の権限に限定します。
ローカル CLI の認証情報や、共同作業者の帳簿ロールは別管理です。

## どこからでもできること

- **レポートを読む** — `get_report` で試算表、損益計算書、貸借対照表、科目元帳、
  グループ別集計を取得します。通常の帳簿は記帳済み仕訳、名前付きビューは現在の
  承認済み計算元帳を使います。取得できる場合は同期時点 `figures_as_of` も返します。
- **資産の増減を確認する** — `get_report(report="cashflow")` は従来の名前です。
  売掛金や固定資産も含む全資産の月別の増減を集計し、振替は両側に計上されます。
  キャッシュ・フロー計算書ではありません。
- **仕訳と科目を読む** — `list_accounts`、`search_journals`、`get_journal` を使います。
  検索条件は AND で組み合わせます。金額の下限・上限は最小通貨単位の非負整数です。
  同じ条件で `nextCursor` を渡して続きを読みます。検索結果の `journal_path` で仕訳を指定し、
  締め済み年度の仕訳は `closed` と表示します。
- **純資産・保有数量・価格を読む** — `get_networth`、`get_holdings`、`list_prices` は
  同期済みのクラウドデータを読みます。価格一覧は `unit`・`currency`・`year`・`limit`・
  `cursor` を指定でき、`nextCursor` が空になるまで続きを取得します。
  価格は認証されたユーザーのものです。純資産の `as_of` を省略すると集計世代の基準日、
  保有数量では当日を使います。
- **パッケージの参考情報を読む** — `get_book_context` は保存済みの選択、タスク・項目の
  定義、設定、ガイドの節、宣言済みの例を返します。権限と帳簿の版を確認しますが、
  CEL の実行、記録の検証、レシピ計算は行いません。
- **年度の状態を確認する** — `fiscal_years` で open・closed・reopened、仕訳件数、
  締めを妨げる下書きの件数を確認します。
- **元資料をアップロードする** — アップロードの許可と帳簿の Owner/Bookkeeper 権限があれば、
  `create_upload_link(book_id=...)` で画像・PDF 用の一度限りのリンクを発行できます
  （15分、10 MB まで）。スキャン後に `raw/uploads/` へ保存します。`journal_path` は受け付けず、
  仕訳の編集や添付の変更は行いません。画面の到着確認を待ち、仕訳との関連付けはローカルで行います。
- **既存の受信アドレスを調べる** — `get_inbox_address` は既存の情報を読むだけで、
  メール送信やアップロードリンクの作成は行いません。

クラウド帳簿は `list_books` が返す `book_id` で指定します。`get_report` の引数は種類に応じて、
試算表・貸借対照表は `as_of`、損益は `from`・`to`、元帳は `account` と期間または `as_of`、
集計は `by` と期間または `year`、資産増減は `year` を使います。
対象外の引数、型の誤り、不明な引数、開始・終了の逆転は無視せずエラーにします。

純資産は Web の帳簿横断レポートと、**ユーザーごとに UTC の1日1回**の自動集計を共有します。
日付、帳簿の選択、通貨を変えても取得済みの入力を更新しません。
`snapshot.generatedAt` と `snapshot.nextRefreshAt` が集計の時点を示します。
同期した変更を早く反映するには、Web のダッシュボードまたは純資産で**集計を実行**します。
リモート MCP は更新後の集計を読みますが、その手動更新操作自体は実行できません。

## あえてできないこと

仕訳の作成・編集・削除、価格の記録、補完の適用、
レシピ計算、転記・承認、年度の締め・再開はできません。
従来の下書き操作は削除しました。元資料のアップロードは明示的に許可した場合に利用でき、
会計記録の作成や変更は行いません。
変更はローカル CLI またはローカル MCP で行い、選択した会計ルールの実行と検証を経て同期します。

## コンピュータの前か、外出先か

| 状況 | 使うもの | 利用できること |
| --- | --- | --- |
| コンピュータの前 | [ローカル設定](cli-and-llm.md) | 手元のファイルで作成 → 検証 → 転記 → 同期 |
| 外出先 | リモートコネクタ | クラウドのレポート・仕訳・参考情報の閲覧と、任意の元資料アップロード |

両方を設定できます。両方が見える AI には、未同期の編集も読めるローカルを優先するよう案内します。

## 接続の解除

AI アプリでコネクタを削除するか、IrisBooks の「あなたの設定 → 接続中のアプリ」で
**接続解除**を選びます。解除が完了すると次のリクエストから拒否し、受け付け済みの処理は
完了する場合があります。共同作業者の帳簿ロールは、帳簿の「設定 → 権限」で別途管理します。
